# 按证据选择的阅读检查点

这些是阅读时的提醒，不是每篇报告必填的检查表。按研究实际设计选用相关段落；正文解释影响科学主张的结果，放入相应图组。确认状态、核查依据和来源定位保存在已有工作索引，按 [证据规则](evidence-rules.md) 组织，不在这里另建记录系统。

## 多队列、嵌套样本与统计单位

当存在多个队列、同一个体的多份材料或多层测量时启用；简单单层研究不必新增表格。

- 对支撑核心结论的实验，交代 `队列/子集 → 个体 → 组织/时间点 → 切片/区域 → 细胞/spot/测量` 中实际存在的层级、数量及配对关系。区分独立个体、生物学重复、技术重复与有效测量数；不同实验可能使用不同子集，不能把总入组数套到所有面板。
- 根据对应 Methods、图注或统计说明确认每项主要检验的分析单位：个体聚合值、组织、细胞，或考虑聚类/嵌套关系的模型。检查误差线、区间、分母及配对是否与该单位一致；大量细胞或切片不能自行扩大独立个体数。
- 方法不清时解释实际分析单位或嵌套依赖处理缺少哪些说明，以及这会怎样影响推断。已读位置留工作索引。仅有多层样本或细胞级 P 值时，不直接断言伪重复；明确将相关测量作为独立重复且未处理依赖时，才据此批评具体推断。
- 发现、验证、治疗前后及不同模态之间是否共享个体、组织或时间点；作者称“独立队列”仍需对应样本来源。样本标识或来源信息不足时，在工作索引保留“重叠未核实”，正文解释这对验证独立性的影响；不要把同一数据的不同算法当作独立重复。
- 必要时在原设计表中增加 `队列/子集｜各层数量与关系｜主要比较及分析单位`，仅列影响当前结果的行；来源与确认状态留工作索引。

## 关键公开数据与验证角色

当公开数据直接支撑核心发现、训练/验证或跨队列主张时启用；无关资源入口无需逐项展开。

- 在现有数据入口或证据索引中对应 `数据集编号/版本 → 实际样本子集与筛选条件 → 发现/训练/调参/验证/参考角色 → 支持图表或主张`。同一编号可含多个批次、患者或任务，不能用数据库总样本数代替本文实际子集。
- 在工作索引标明映射依据是论文报告、已读样本表/元数据还是实际数据检查；下载链接可访问不等于已核对样本。未获取相应信息时记录无法确认的子集或角色，不为填表自动下载原始数据。
- 样本重叠按个体标识、来源队列、采样时间与可用元数据判断；在工作索引记录“已核实重叠”“已核实独立”或“未核实”及依据，正文保留影响结论的设计信息。同一来源中的不同 accession 不能自动保证独立，不同来源也不能自动认定重叠。
- 独立验证需联系其实际用途：固定发现阶段选出的特征/阈值后验证，还是重新筛选、调参或重复描述同一信号。只有已核查的流程才能支持相应评价；原始数据重分析与文献阅读的核查范围按证据规则区分。

## 人群、分层与治疗

- 个体如何纳入、排除和分组；终点是否预先定义；采样在治疗前还是治疗后；各实验使用哪些重叠或独立个体。
- 组间差异能否受疾病阶段、既往治疗、组织部位或其他混杂影响；是否有适当的调整或匹配。
- 多层样本和验证独立性按上面的相关检查处理；阈值是否在验证前确定。
- 研究支持一般预后、反应关联还是差异治疗获益；后者通常需要对应比较设计。局限写到具体主张，不把所有人群论文要求成随机试验。

## 实验与机制

- 当作者提出 A→B→C 等机制链时，逐条检查 A→B、B→C 以及贯穿链条的主张，而不是用一项阳性实验概括整条因果链。按需要在现有索引中补 `所述边/关系｜实际证据与对照｜可支持范围｜替代解释/未验证环节`，保留每条边所在的体系与条件。
- 对照是否隔离了所提机制，随机化/盲法/重复如何描述，多个实验是否来自独立生物学重复。
- 扰动是否直接影响候选因素；脱靶、活性/数量变化、细胞系特性是否构成竞争解释。
- 配体、受体、下游改变、表型之间哪条边被直接测试，哪条依靠预测；双向扰动、阻断或救援是否真正需要才能区分模型。
- 将表达相关、空间邻近、候选通讯、时间关系与干预分别接到实际测试的边。A 的扰动同时改变 B 和 C 可支持该体系中的影响，但不能单独证明 B 中介 A→C；功能回补、B 的损失/阻断及特异性对照分别回答不同问题，按所声称的必要性、充分性或中介关系评价。
- 蛋白表达、代谢评分和直接代谢通量分别是什么证据；共培养设计能否确定信号方向。
- 联合治疗评估的是优于单药、相加还是协同；不把更低终点值直接升级为协同证明。
- 后续建议回指具体缺口：要区分哪两种解释、测试哪条边、需要什么比较和判定指标。证据仅来自一个模型时写明跨体系验证的用途；不机械要求每篇补齐所有扰动或救援实验，也不把未读材料中的实验视为未做。

## 组学、空间与多模态配对

- 各层数据来自同一个体、相邻切片、相同时间点还是外部参考；配对误差和分辨率能否改变解释。
- 细胞类型注释、参考数据和解卷积的覆盖能力如何；混合 spot、组成效应或批次是否影响差异。
- 空间热点、邻近与区域边界如何定义，检验是否考虑空间依赖；参数或定义改变是否可能动摇结果。
- 差异分析、轨迹和通讯算法是否共用同一信号；所谓验证是否新增了独立测量或独立样本。
- 标志基因/评分是状态代理还是直接功能测量；避免把工作性群名直接当作已证实功能。

## 时间、谱系与克隆

- 时间证据来自同一对象追踪、不同时间点样本、计算排序还是理论模型；分别解释。
- 标记效率、同色碰撞、克隆边界与空间连通规则有哪些假设；同一突变是否可能独立出现。
- 突变检测的覆盖范围、误差过滤、等位基因频率与检测限如何影响克隆识别；有限面板不能代表全基因组。
- 正选择、克隆扩大、肿瘤位置关联和恶性转化不是同一终点。模型拟合出的有效参数不是直接逐次观测行为。

## 算法、预测与评测

- 明确任务、输入、输出、训练目标或推断规则，方法相对已有工具新增了什么。
- 重建操作流程时区分论文叙述顺序与计算执行顺序，写清特征选择、数据划分、参数拟合及测试各在哪一步；训练拟合与独立测试不能因表格排版被误写成先拟合后划分。保留作者实际流程中的问题，改进流程另标为本次建议，不默默替作者修正。
- 数据划分是否以独立个体为单位，是否存在样本、特征筛选或预处理泄漏；外部验证是否独立。
- baseline、数据、调参预算和评价指标是否可比；改进是否来自数据或实现差异。
- 消融/敏感性/稳健性分析是否检验了作者真正提出的关键模块；缺少这些分析对结论影响多大。
- 性能、校准、泛化、解释性、成本各有哪些实际证据；没有运行时间、硬件或理论复杂度就标未报告，避免编造算力需求。

## 无图、纯观察或其他组织形式

- 主表、公式、定理或结果小节可代替 Figure 作为解读单元；解释职责保持一致。
- 纯观察研究按其关联目标评价，指出因果边界，不把没有干预自动当作研究失败。
- 综述或观点文章超出默认原创研究报告时说明体裁，按论点和引用组织，不能捏造自己的实验、样本或 Results。
