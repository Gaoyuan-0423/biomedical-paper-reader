# v0.13.0

## 中文

新增外观设置，双平台验收后正式发布并设为 Latest。

- 界面字号 12–18、笔记字号 12–24 独立调节，分别作用于应用文字和阅读／读图笔记。PDF 缩放、裁剪坐标及论文原图不受字号影响。
- 蓝、青、紫三种配色；浅色、深色和跟随系统三种模式。系统模式在操作系统切换配色时实时更新。
- 外观即时生效并自动保存，加载或保存失败可重试；与界面语言独立修改，重启后恢复。
- 切换外观不改写研究内容、不重建编辑草稿，也不改变导出排版。保留 v0.12.1 的观察持久化、旧图注升级及中英文解读。

下载 [macOS ARM64 DMG](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.13.0/BioReader-v0.13.0-macos-arm64.dmg)、[Windows x64 安装版](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.13.0/BioReader-v0.13.0-windows-x64-setup.exe) 或 [便携 ZIP](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.13.0/BioReader-v0.13.0-windows-x64.zip)。更新前正常退出旧版，文献、笔记、模型设置保留在独立数据目录。Windows ZIP 需完整解压，保留服务目录。SHA256SUMS.txt 提供三份程序包校验值。

具体测试与限制见 [App 验证记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.13.0/app/tests/README.md) 及本页最终原生构建记录。本轮不调用真实模型、不新增科学阅读质量评分。系统文件对话框与系统字体行为遵循操作系统；PDF 内容保持原始页面配色。Mac 未做 Apple Developer ID 公证，Windows 未做发布者签名。

## English

Adds appearance preferences. Publish as a regular Release and Latest after native acceptance on both platforms.

- Adjust interface font size (12–18) and note font size (12–24) independently. PDF scale, crop coordinates and source figures remain unchanged.
- Choose blue, teal or violet accents and light, dark or system appearance. System mode responds to operating-system color changes immediately.
- Preferences apply instantly, save automatically and restore after restart. Load/save failures can be retried. Appearance and language updates preserve each other's fields.
- Changes preserve research content, editor drafts and export formatting. Retains v0.12.1 observation persistence, legacy caption upgrades and bilingual generation.

Download the [macOS ARM64 DMG](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.13.0/BioReader-v0.13.0-macos-arm64.dmg), [Windows x64 installer](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.13.0/BioReader-v0.13.0-windows-x64-setup.exe) or [portable ZIP](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.13.0/BioReader-v0.13.0-windows-x64.zip). Quit the old app normally before updating; libraries, notes and model settings remain in their separate data directory. Extract the Windows ZIP completely and retain its service directory. SHA256SUMS.txt lists all three package hashes.

See the [App validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.13.0/app/tests/README.md) and final native-build evidence for actual results and limits. This release makes no live-model calls or new scientific-quality claims. Native file dialogs and system font behavior follow the operating system; PDF pages retain their original colors. Apple Developer ID notarization and Windows publisher signing are not provided.
