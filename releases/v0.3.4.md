# v0.3.4

## 中文

本版为 CI 与发布维护补丁，基于已发布的 v0.3.3。论文阅读行为和 App 功能没有变化。

- 两份工作流的 `actions/checkout` 升级至 v7.0.1、`actions/setup-python` 升级至 v7.1.0，均原生使用 Node.js 24，继续固定官方发布对应的完整提交 SHA。
- CI 与发布任务固定使用 `ubuntu-24.04`，避免 `ubuntu-latest` 的操作系统迁移影响现有环境。
- 启用 Dependabot，每周一北京时间 09:00 检查 GitHub Actions；有新版时自动创建更新 PR，由现有 CI 验证、维护者审阅合并。不自动合并或发布，也不自动升级 Ubuntu/Python 版本。
- 同步中英文版本说明、维护指引和独立验证记录；保留 v0.3.3 原标签及历史评测记录。

验证范围：25 项既有记录／发布元数据回归、版本一致性、仓库链接／记录完整性及脚本编译检查。未重新运行真实论文、视觉／语言阅读案例或 App 端到端测试；本版不新增行为准确率或性能声明。

## English

This is a CI and release-maintenance patch based on the published v0.3.3. Paper-reading behavior and App functionality are unchanged.

- Both workflows upgrade `actions/checkout` to v7.0.1 and `actions/setup-python` to v7.1.0. Both use Node.js 24 natively and remain pinned to the full commit SHAs of their official releases.
- CI and release jobs use `ubuntu-24.04`, avoiding operating-system changes through the moving `ubuntu-latest` label.
- Dependabot checks GitHub Actions every Monday at 09:00 Asia/Shanghai. When newer versions are available, it opens update PRs for existing CI checks and maintainer review. It does not automatically merge or publish, or upgrade Ubuntu/Python versions.
- Bilingual version declarations, maintenance guidance, and a separate validation record are updated. The v0.3.3 tag and historical evaluation records are preserved.

Validation covers 25 existing reading-record/release-metadata regression tests, version consistency, repository links and record integrity, and script compilation. Real-paper trials, visual/language reading cases, and App end-to-end tests were not rerun. This release makes no new claims about behavioral accuracy or performance.
