# v0.10.0

## 中文

BioReader 原文联动与 Go + MyGo 桌面预览版。按 **Pre-release** 发布，保留 v0.3.4 稳定版。

- 精读笔记中的原文按钮关联实际提供给模型的片段，点击前核验笔记版本和 PDF 文件版本；正文与补充各用自己的页码，有真实坐标时高亮。旧笔记不自动猜测出处。
- 新增可折叠的章节／图表／笔记导航：使用 PDF 原生书签，按当前文件查看图表，并定位笔记对应图片或标题。
- 生成中断时保留部分内容与来源，防止旧生成覆盖新的人工编辑。Markdown 代码、参考文献与图片中的示例标记不作为来源；导出保留人可读文件名、页码及原文摘录。
- 桌面窗口改用 Go + [MyGo](https://github.com/egoist/mygo)，Python 阅读服务和 PDF 库一并内置。沿用蓝白界面、文献数据、标签、资源整理、检索和 Zotero MCP。

### 安装与更新

- Apple 芯片 Mac：[BioReader-v0.10.0-macos-arm64.dmg](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.10.0/BioReader-v0.10.0-macos-arm64.dmg)。打开 DMG，将 BioReader.app 拖入应用程序。
- Windows 10／11 x64：[安装 EXE](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.10.0/BioReader-v0.10.0-windows-x64-setup.exe)，或下载 [便携 ZIP](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.10.0/BioReader-v0.10.0-windows-x64.zip) 完整解压后运行 BioReader.exe。便携版必须保留全部随附文件。

两平台无需另装 Python；Windows 需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。更新前退出旧版。macOS 数据仍在 `~/Library/Application Support/BioReader/`，Windows 仍在 `%LOCALAPPDATA%\BioReader`，更新程序保留论文、笔记与设置。安装包未进行 Apple Developer ID 公证或 Windows 代码签名。校验值见同页 SHA256SUMS.txt。

窗口关闭时先保存笔记与阅读位置；正在生成、导入或存在研究表单草稿时会提示先处理。此版不提供应用内自动升级或跨电脑文库同步。按章节续写、笔记历史版本、完整 GEO 样品列表和备份迁移界面仍是后续方向。

验证范围见 [App 测试记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.10.0/app/tests/README.md)。工程测试使用合成材料与模拟模型，未新增真实模型的科学解读质量评分；原生自动化与人工系统对话框验收分别记录。Skill 规则及六份 references 未变，仅更新版本。

## English

BioReader source-linked reading and Go + MyGo desktop **Pre-release**. Stable v0.3.4 remains available.

- Link close-reading notes to actual original excerpts supplied to the model. Resolve against the current note and PDF revision before navigation; main and supplementary files retain their own page numbers, with highlighting where reliable coordinates exist. Older notes receive no guessed sources.
- Add a collapsible navigator for native PDF bookmarks, figures in the active document, and note headings. Figure selection also locates the matching note image.
- Preserve interrupted output and its source snapshot, prevent older generation from overwriting newer edits, and exclude Markdown code/reference examples from source binding. Exports retain readable file names, PDF pages and quotations.
- Use a Go + [MyGo](https://github.com/egoist/mygo) desktop shell with the existing Python reading service and PDF libraries bundled. Retain the blue-and-white workspace, library data, tags, sample records, search and Zotero MCP.

### Installation and updates

- Apple silicon Mac: open `BioReader-v0.10.0-macos-arm64.dmg` and drag BioReader.app into Applications.
- Windows 10/11 x64: use `BioReader-v0.10.0-windows-x64-setup.exe`, or extract the complete `BioReader-v0.10.0-windows-x64.zip` and run BioReader.exe, retaining all accompanying files.

Python installation is not required. Windows needs [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). Quit the old app before updating. Data stays in `~/Library/Application Support/BioReader/` on macOS and `%LOCALAPPDATA%\BioReader` on Windows. Packages have no Apple Developer ID notarization or Windows code signature. See SHA256SUMS.txt for asset hashes.

Closing saves notes and reading position; active generation/import or research-form drafts require attention before exit. There is no in-app updater or cross-device library sync. Section-level continuation, note version history, complete GEO sample lists and backup/migration UI remain future work.

See the [App validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.10.0/app/tests/README.md) for exact coverage. Engineering checks use synthetic materials and simulated model responses; they do not score scientific interpretation. Native automated checks and manual system-dialog acceptance are recorded separately. Skill rules and all six references remain unchanged apart from the version label.
