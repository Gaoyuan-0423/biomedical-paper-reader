# v0.8.0

## 中文

BioReader 样品整理与全库检索预览版，作为 **Pre-release** 发布。保留 v0.3.4 稳定版。

### 本次变化

- 数据与复现分别保存物种、组织、疾病、技术、平台、实验分组和论文实际样本量，保留原始样品说明及多编号分组。GEO 收录总量仍独立展示。
- 精读样品列采用明确标签；本地整理器仅从标签或独立表格列抽取字段。旧自动记录兼容升级，更新前备份；人工修改继续保留。
- 按物种／组织／疾病／技术／平台组合筛选，条件同时满足才显示。导出已应用的当前结果为资源 CSV 或去重编号 TXT，支持当前论文与全库范围。CSV 包含论文身份、样品字段和原文来源，带 UTF-8 BOM 与公式前缀保护；编号只取明确编号及支持的仓库链接。
- 新增「搜索正文与笔记」入口，在本机正文、补充 PDF 文本层和已保存笔记中查找关键词或原文短语，每次加载 20 条。PDF 结果验证文件版本后跳页，有坐标时高亮；笔记结果打开已保存笔记，暂不定位具体句子。
- 保留蓝白界面、Zotero MCP 导入、单篇原文问答和直接保存流程，没有恢复阅读进度、决策、待办或资源核对标签。

### 安装与验证范围

Apple 芯片 Mac 的预览附件名为 `BioReader-v0.8.0-macos-arm64.zip`，以发布页实际提供为准。退出旧版后替换 `BioReader.app`；用户目录中的论文、笔记和设置保留。使用同页的 `SHA256SUMS.txt` 可执行 `shasum -a 256 -c SHA256SUMS.txt` 校验。

全文搜索和资源整理在本机执行，不调用模型；旧 PDF 首次提取文本缓存可能较慢，扫描件不做 OCR。此版不包含语义检索、跨篇 AI 问答、自动文献跟踪、开放全文获取、BibTeX、备份界面或对外 MCP 服务。功能组织借鉴 BiblioCell 思路，代码与素材独立实现。

验证采用隔离合成文件和记录，不读取私人文献库或调用真实模型，未重新评测精读科学质量或实际模型字段提取准确率。实际回归、浏览器及打包结果见[验证记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.8.0/app/tests/README.md)。原生 WebKit 本轮未重新验收，应用未进行 Apple 开发者签名或公证。

## English

This BioReader **Pre-release** adds structured sample records and library-wide local search. Stable v0.3.4 remains available.

### Changes

- Save species, tissue, disease, assay, platform, experimental groups and actual paper sample counts separately while retaining the original sample description and grouped accessions. GEO collection totals remain independent.
- Close-reading prompts request explicit sample labels; the local organizer reads only labeled fields or dedicated table columns. Existing automatic records can be upgraded with a backup before replacement, while manual edits are preserved.
- Combine species/tissue/disease/assay/platform filters with AND matching. Export the applied current results as resource CSV or a deduplicated accession TXT file, within one paper or across the library. CSV includes paper identity, sample fields and provenance, uses UTF-8 BOM and protects formula prefixes. Accession export uses only explicit identifiers and supported repository links.
- Search local main PDFs, supplementary PDF text layers and saved notes for keywords or source phrases, loading 20 results at a time. PDF results verify the file revision before page navigation, with highlighting when coordinates exist. Note results open saved notes without exact sentence positioning.
- Keep the blue-and-white workspace, Zotero MCP imports, per-paper questions and direct resource saving. Reading progress, decisions, tasks and resource verification labels are not restored.

### Installation and validation scope

The Apple silicon preview asset is named `BioReader-v0.8.0-macos-arm64.zip`; use the assets actually published on this page. Quit the old app before replacing `BioReader.app`. Existing papers, notes and settings in the user directory are retained. Download `SHA256SUMS.txt` and run `shasum -a 256 -c SHA256SUMS.txt` to verify the assets.

Search and resource organization run locally without model calls. Older PDFs may take longer to create their text cache on first use; scanned PDFs are not OCRed. This release does not add semantic search, cross-paper AI answers, automatic literature tracking, open-access retrieval, BibTeX, backup UI or an outward-facing MCP server. BiblioCell informed the feature organization; implementation and assets are independent.

Validation uses isolated synthetic files and records without accessing private libraries or calling a real model. Scientific reading quality and real-model field-extraction accuracy were not reassessed. See the [validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.8.0/app/tests/README.md) for actual regression, browser and build results. Native WebKit was not rechecked; the app has no Apple Developer ID signature or notarization.
