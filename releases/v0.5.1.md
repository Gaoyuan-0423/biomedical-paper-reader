# v0.5.1

## 中文

BioReader 自动标签修复预览版。沿用 v0.5.0 蓝白研究工作台，补齐精读／速读后自动产生主题标签的流程。本版为 **Pre-release**，现有 v0.5.0 附件及 v0.3.4 稳定版保留。

### 变化与使用

- 精读／速读笔记成功保存后，使用已配置的文本模型自动识别主题、研究对象和技术标签，显示在论文标题及文献列表中。标签识别增加一次简短模型请求。
- 旧文献点击标题下的「识别标签」即可单独补全，无需重新生成笔记。没有配置模型时仍可手动添加或删除标签。
- 已有人工标签保留；模型错误、超时或返回无效格式时不改动原标签。识别期间材料、笔记或标签已变化时拒绝过期结果，可按当前内容重试。
- 笔记保存与标签识别分别处理；标签失败不把已完成笔记标为失败，停止／中断的生成不会触发自动识别。
- 恢复侧栏标签筛选的常显入口，修复快速增删标签丢失、切换论文后迟到响应污染新论文，以及旧标签响应覆盖笔记的问题。

### 下载与验证范围

下载本页 `BioReader-v0.5.1-macos-arm64.zip`，退出旧版后解压并替换 `BioReader.app`。适用于 Apple 芯片 Mac；已有用户目录中的资料和设置保留。可下载 `SHA256SUMS.txt`，在同一目录运行 `shasum -a 256 -c SHA256SUMS.txt` 校验。

85项前端、55项App后端回归与仓库检查通过，5组真实Chrome场景通过，Mac应用完成构建、随包源码一致性、解压及包完整性检查。本版回归使用模拟模型和隔离合成资料，检查自动触发、失败隔离、并发标签编辑及持久化；没有调用真实付费模型，也不声明实际标签准确率或重新评测论文解读质量。浏览器检查与打包验证的详细范围见[验证记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.5.1/app/tests/README.md)。原生 WebKit 窗口本轮未重新验收，应用尚未进行 Apple 开发者签名或公证。

## English

This **Pre-release** adds automatic topic tags after successful deep/quick note generation, retaining the v0.5.0 blue-and-white research workbench. Existing v0.5.0 assets and stable v0.3.4 remain unchanged.

### Changes

- After notes are successfully saved, the configured text model identifies topic, study-object and method tags in one additional short request.
- Existing papers offer a separate “识别标签” (identify tags) action without regenerating notes. Manual tag management remains available without a configured model.
- Existing manual tags are retained. Invalid responses, errors and timeouts leave tags intact. Results based on changed source material, notes or tags are rejected and can be retried.
- Tagging failure does not mark saved notes as failed. Stopped or incomplete generation does not trigger automatic tagging.
- Sidebar tag filters are visible again. Per-paper tag edits preserve rapid additions/removals, avoid leaking delayed responses into another paper, and do not overwrite notes with stale metadata.

### Download and validation scope

Download `BioReader-v0.5.1-macos-arm64.zip` for Apple silicon Macs, quit the old app, and replace it with the extracted `BioReader.app`. Existing data and settings in the user directory are retained. Use the accompanying `SHA256SUMS.txt` with `shasum -a 256 -c SHA256SUMS.txt` to verify the archive.

All 85 frontend and 55 app backend tests, repository checks, and five real Chrome scenarios passed. The Mac bundle passed build, bundled-source consistency, extraction and integrity checks. Regression tests use mocked model responses and isolated synthetic materials for automatic triggers, failure isolation, concurrent tag edits and persistence. No live paid model or new real-paper scientific-quality evaluation was run, and no real-world tagging-accuracy claim is made. See the [validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.5.1/app/tests/README.md) for browser and bundle checks. Native WebKit was not rechecked in this patch; the app has no Apple Developer ID signature or notarization.
