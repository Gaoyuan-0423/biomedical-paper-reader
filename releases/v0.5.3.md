# v0.5.3

## 中文

BioReader 资源表格与 GEO 样品信息预览版，作为 **Pre-release** 发布。保留蓝白界面、历史版本和 v0.3.4 稳定版入口。

### 本次变化

- 移除阅读进度、阅读决策和「判断阅读价值」按钮，保留星标、标签及实际操作待办。
- 「数据与复现」按精读表格展示资源、用途、编号／链接、使用条件和样品／材料。同一行的多个编号保持分组，支持命名队列及细胞系，不再重复显示原始 Markdown 笔记片段。
- 完整精读模板增加样品／材料列；成功保存后本地自动整理，已有笔记可手动重新整理。旧的未改动自动记录可转换成表格，替换前完整备份，人工及已核对记录保持不变。
- GSE 编号可手动补充 GEO 公开的研究设计、实验类型、平台、总样本量和至多 3 个样品示例。示例显示物种、来源、特征和建库方式，附 GEO 原始链接；总量不等于论文实际用量。
- GEO 元数据独立缓存，打开页面只读本地缓存，按钮才联网。无需模型 Key、不下载矩阵、不覆盖人工内容、不自动确认核查状态；当前不纳入报告导出。
- 编辑、搜索、跨论文编号关联和报告导出支持新字段。沿用此前标签超时延长与自动重试修复。

### 下载与验证范围

下载 `BioReader-v0.5.3-macos-arm64.zip`，退出旧版后用解压出的 `BioReader.app` 替换。适用于 Apple 芯片 Mac，用户目录中的论文、笔记和设置保留。`SHA256SUMS.txt` 可用于 `shasum -a 256 -c SHA256SUMS.txt` 核对附件。

验证覆盖隔离合成资源表、旧记录迁移与备份、人工内容保护、GEO 缓存／错误／异步返回、导出和浏览器布局。GEO 联网另用公开记录实测；没有调用真实付费模型，也不声明精读准确率或全部资源覆盖率。详细结果见[验证记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.5.3/app/tests/README.md)。原生 WebKit 本轮未重新验收，应用尚未进行 Apple 开发者签名或公证。

## English

This **Pre-release** adds structured resource tables and on-demand GEO sample metadata. The blue-and-white workspace, earlier releases and stable v0.3.4 remain available.

### Changes

- Remove reading-progress controls, decision controls and the reading-value button. Keep favorites, tags and actionable tasks.
- Present resources, purposes, grouped identifiers/links, usage conditions and paper-used sample/material details. Preserve multi-accession rows, named cohorts and cell lines instead of repeating raw Markdown excerpts.
- Deep-reading output includes a sample/material column. Completed notes are extracted locally; existing notes can be re-extracted. Untouched old automatic records can be converted with a complete backup, while human-edited and verified records are retained.
- GSE records offer manual GEO lookup for public study design, experiment types, platforms, series sample counts and up to three sample examples with organism, source, characteristics and library strategy. Each example links to GEO; series totals are distinct from paper-used sample counts.
- GEO metadata is cached separately. Opening the view reads local cache only; explicit lookup buttons make network requests without a model key or matrix download. They never replace curated fields or confirm verification; GEO supplements are currently excluded from report exports.
- Editing, searching, shared-accession matching and exports support the new fields. Earlier tag timeout and retry improvements remain in place.

### Download and validation scope

Download `BioReader-v0.5.3-macos-arm64.zip` for Apple silicon Macs, quit the old app and replace it with the extracted `BioReader.app`. Existing papers, notes and settings in the user directory are retained. Verify attachments using `shasum -a 256 -c SHA256SUMS.txt`.

Validation uses isolated synthetic resource tables for migration/backups, human-edit protection, GEO caching/errors/asynchronous completion, exports and browser layouts. Public GEO records were separately checked live. No paid model was called and no reading-accuracy or exhaustive-extraction claim is made. See the [validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.5.3/app/tests/README.md). Native WebKit was not rechecked; the app has no Apple Developer ID signature or notarization.
