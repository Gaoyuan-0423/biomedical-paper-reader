# v0.14.0

## 中文

BioReader 可按课题收集论文、补齐缺失的材料，并将多篇论文的证据放在同一张比较表里。

- 在一个入口预览 DOI 或 PMID 清单，把选中的论文加入已有课题库。一篇论文可被多个课题共用。
- 在论文页查找开放全文，或在课题库中选择缺正文的论文批量处理。结果按篇记录，支持停止后续查找、重试失败项和打开候选来源。能否下载取决于来源开放情况和文件身份核对。
- 主动查找文章列明的补充材料，自选所需文件。补充 PDF 可用于阅读和取图，支持的表格和压缩包作为该论文的附件保存。
- 按课题保存 PubMed 检索式。手动刷新最近 50 个匹配结果，可预览未标为已看的 PMID 并选择导入。
- 从正文或补充 PDF 选字记录证据。跨篇比较可保存研究对象、关键对照、引用页、图表和人工判断，并提示共同数据编号。
- 在课题内收藏和检索带标签的图表。七个样品字段可各自保留原句、PDF 文件和页码，随报告和 CSV 导出。

桌面附件提供 Apple 芯片 Mac 的 DMG、Windows x64 安装 EXE 和便携 ZIP。SHA256SUMS.txt 列出三个文件的校验值。更新前正常退出应用，安装包和本机文献数据分别存放。

## English

Organize papers by project, retrieve available full texts and supplements, and compare evidence across papers.

- Preview DOI and PMID lists and add selected records to a project. Projects can share the same papers and local notes.
- Look for an open main PDF on a paper or run a batch over missing PDFs in a project. Review per-paper results, stop the queue, retry incomplete items, and inspect candidate sources.
- Discover supplementary files linked to an article and choose which to download. Read supplementary PDFs in BioReader and keep supported tables and archives as paper attachments.
- Save PubMed queries per project. Refresh the latest 50 results on demand, mark a result set as seen, or preview unseen PMIDs for import.
- Save PDF selections as evidence and compare populations, controls, sources and human judgments. Shared dataset accessions are surfaced for review.
- Save and tag figures across papers. Individual sample fields can carry their own source excerpt, file and page in report and CSV exports.

Desktop assets include an Apple silicon macOS DMG, Windows x64 installer and portable ZIP, with SHA-256 checksums. Quit BioReader before installing. Application data live outside the installed program.
