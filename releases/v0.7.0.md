# v0.7.0

## 中文

BioReader Zotero MCP 导入预览版，作为 **Pre-release** 发布。保留 v0.3.4 稳定版。

### 本次变化

- 新增 Zotero 入口：检索当前文库、预览文献信息和附件，再明确选择仅导入元数据或一份本机存储 PDF。
- 首批适配 [54yyyu/zotero-mcp](https://github.com/54yyyu/zotero-mcp) 的 Streamable HTTP，处理 JSON 与 SSE 响应。设置默认地址为 `http://127.0.0.1:8000/mcp`，支持可选 Bearer Token 和本机 Zotero `storage` 目录。
- 按来源文库／条目 Key 和 DOI 查重；命中已有文献时返回原记录，可点击「打开文献」查看，不覆盖正文、笔记或人工修改。
- 支持已下载到本机的 `imported_file`、`imported_url` PDF。链接文件、网址附件、仅云端文件或远端服务器路径不作为本机 PDF 读取；没有可用文件时可选择仅导入元数据。
- 可以先保存设置、之后再安装服务。BioReader 不安装或启动 Zotero MCP、不自动导入整库，也不写回 Zotero；保留 PDF 选字问答、来源导航及已有导出流程。

### 安装与验证范围

Apple 芯片 Mac 的预览附件名为 `BioReader-v0.7.0-macos-arm64.zip`，以发布页实际提供的附件为准。退出旧版后替换 `BioReader.app`；用户目录中的论文、笔记和设置保留。附件可用 `shasum -a 256 -c SHA256SUMS.txt` 校验。

Zotero MCP 服务需独立安装、启动；[连接说明](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.7.0/app/README.md#连接-zotero-mcp)提供上游命令及本机附件配置。首版不覆盖其他同名 MCP 服务、stdio、旧式 SSE 传输、自动同步或远端 PDF 下载。

本轮验证使用模拟 MCP 响应与隔离合成文献，不读取私人 Zotero 库、不安装用户服务或调用付费模型。模拟协议验证不等于真实库端到端兼容；实际回归、浏览器与打包结果见[验证记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.7.0/app/tests/README.md)。原生 WebKit 本轮未重新验收，应用未进行 Apple 开发者签名或公证。

## English

This BioReader **Pre-release** adds Zotero MCP imports. Stable v0.3.4 remains available.

### Changes

- Search the active Zotero library, preview metadata and attachments, then explicitly import metadata only or one locally stored PDF.
- The first adapter targets [54yyyu/zotero-mcp](https://github.com/54yyyu/zotero-mcp) over Streamable HTTP, including JSON and SSE responses. Settings provide the default endpoint `http://127.0.0.1:8000/mcp`, an optional Bearer Token and a local Zotero `storage` directory.
- Deduplicate by source library/item key and DOI. Existing records are returned for explicit opening without replacing their PDFs, notes or manual changes.
- Import locally downloaded `imported_file` and `imported_url` PDFs. Linked files, URL-only attachments, cloud-only files and server-side paths are outside this local PDF route. Metadata-only import remains available when no local PDF can be read.
- Save settings before installing the service. BioReader does not install or start Zotero MCP, automatically import an entire library, or write back to Zotero. PDF selection questions, source navigation and existing exports remain available.

### Installation and validation scope

The Apple silicon preview asset is named `BioReader-v0.7.0-macos-arm64.zip`; use the assets actually provided on the release page. Quit the old app before replacing `BioReader.app`. Existing papers, notes and settings in the user directory are retained. Verify attachments with `shasum -a 256 -c SHA256SUMS.txt`.

Install and run Zotero MCP separately using the [upstream setup guide](https://github.com/54yyyu/zotero-mcp/blob/main/docs/getting-started.md). This first adapter does not cover other Zotero MCP implementations, stdio, the legacy SSE transport, automatic synchronization or remote PDF downloads.

Validation uses mocked MCP responses and isolated synthetic papers, without reading a private Zotero library, installing a user service or calling a paid model. Protocol fixtures do not establish end-to-end compatibility with a real library. See the [validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.7.0/app/tests/README.md) for actual regression, browser and build results. Native WebKit was not rechecked; the app has no Apple Developer ID signature or notarization.
