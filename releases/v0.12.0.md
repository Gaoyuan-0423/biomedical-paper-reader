# v0.12.0

## 中文

BioReader 读图笔记查看器预览版。本版以 **Pre-release** 发布，稳定版及 Latest 保留 **v0.3.4**。

- **图像与读图笔记对照**：在「图库」点击图片缩略图或「查看笔记」，左侧查看图片，右侧完整显示该图已保存的读图观察。右侧支持 Markdown 标题、列表、表格与代码，并可展开原图注。图像可适应窗口、放大、缩小与滚动；窄窗口改为上下排列。
- **已有结果直接可看**：打开查看器无需重新提取、重新读图或重新生成精读／速读笔记，不会自动调用模型。没有保存的读图观察时显示提示，可回图库主动使用原有「读图」功能。
- **与正文笔记分开**：查看器只读该图的独立观察，不自动追加或改写论文正文笔记，也不根据正文笔记猜测缺失的图级结果。已有模型观察保持原内容与原语言。
- **受限 Markdown**：不执行 HTML，不加载 Markdown 内嵌图片（包括 `figure:`），不激活内部来源或图片伪引用；普通安全 HTTP／HTTPS 外链可打开。左侧图片由当前文献的本地图记录提供，不使用模型输出的地址。
- 主动读图遇到超时或连接错误时显示明确提示，保留已有读图结果，不用错误提示覆盖观察内容。
- 保留 v0.11.1 的补充图图注修复、已有数据与中英界面。旧自动图注需要更新时，仍在对应 PDF 的图库中主动「重新提取」；这与查看已经保存的读图笔记是两个独立操作。

### 安装与更新

- Apple 芯片 Mac：[BioReader-v0.12.0-macos-arm64.dmg](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.12.0/BioReader-v0.12.0-macos-arm64.dmg)，打开 DMG，将 `BioReader.app` 拖入“应用程序”。
- Windows 10 / 11 x64：[安装 EXE](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.12.0/BioReader-v0.12.0-windows-x64-setup.exe)，或 [便携 ZIP](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.12.0/BioReader-v0.12.0-windows-x64.zip)。ZIP 须完整解压，保留 `BioReaderService` 目录及全部随附文件，再打开 `BioReader.exe`。

两平台使用 Go + MyGo 外壳及随包 Python 阅读服务，用户无需安装 Python。Windows 需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。更新前正常退出旧版；用户数据继续保存在 macOS 的 `~/Library/Application Support/BioReader/` 或 Windows 的 `%LOCALAPPDATA%\BioReader`，替换程序保留论文、笔记和设置。

程序附件以发布页实际提供为准，下载后可按 `SHA256SUMS.txt` 核对。Mac 包未做 Apple 开发者签名或公证，Windows 包未做发布者代码签名。本版不包含应用内自动更新或跨电脑文献库同步。

验证范围与实际结果见 [App 验证记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.12.0/app/tests/README.md)。最终原生构建、安装和程序包验收以同版 Release 构建记录为准；浏览器测试不等同于系统 WebView 或原生对话框验收。本轮没有新增真实模型精读或科学解读质量评分，查看已保存的观察不代表重新核实了科学结论。公开仓库不分发用户论文；Skill 仅更新版本，六份参考指令保持不变。

## English

BioReader figure-note viewer preview. This is a **Pre-release**; **v0.3.4** remains the stable Latest release.

- **Read a figure beside its saved observation:** in Figures, click a thumbnail or View notes. The image appears on the left and the complete saved observation on the right, with Markdown headings, lists, tables and code plus an expandable source caption. Fit, zoom and scrolling support image inspection; narrow windows stack the panes.
- **Use existing results immediately:** opening the viewer requires no re-extraction, new model reading or close/quick note generation. It does not call a model. An empty state directs users back to the existing Read figure action when no observation has been saved.
- **Keep paper notes separate:** the viewer reads the figure's own observation without appending to or changing paper-level notes, or guessing missing figure observations from those notes. Existing observations retain their original content and language.
- **Restricted Markdown:** HTML does not execute, embedded Markdown images (including `figure:`) do not load, and internal source/figure pseudo-links do not activate. Safe HTTP/HTTPS links remain available. The image pane uses the current paper's local figure record rather than model-provided addresses.
- A timeout or connection error during an explicitly requested figure reading produces a clear message and preserves the previous observation rather than replacing it with error text.
- Retains the v0.11.1 supplementary-caption fixes, existing data and bilingual UI. To update an old automatic caption, explicitly choose Re-extract for its PDF in Figures; this is separate from viewing an already saved observation.

### Install and update

- Apple silicon Mac: [BioReader-v0.12.0-macos-arm64.dmg](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.12.0/BioReader-v0.12.0-macos-arm64.dmg). Open the DMG and drag `BioReader.app` to Applications.
- Windows 10 / 11 x64: [Installer EXE](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.12.0/BioReader-v0.12.0-windows-x64-setup.exe), or [portable ZIP](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.12.0/BioReader-v0.12.0-windows-x64.zip). Extract the entire ZIP and retain `BioReaderService` and all accompanying files before opening `BioReader.exe`.

Both platforms use Go + MyGo with a bundled Python reading service; users do not install Python. Windows requires [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). Quit the old application normally before updating. Libraries remain in `~/Library/Application Support/BioReader/` on macOS or `%LOCALAPPDATA%\BioReader` on Windows; replacing the application preserves papers, notes and settings.

Use the assets actually listed on the release page and verify them against `SHA256SUMS.txt`. The Mac package has no Apple Developer ID signature or notarization, and the Windows package has no publisher code signature. There is no in-app updater or cross-device library synchronization.

See the [App validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.12.0/app/tests/README.md) for scope and actual results. Final native builds, installation and artifact validation are documented with the matching Release; browser tests do not substitute for system WebView or native-dialog acceptance. This version adds no live-model close-reading or scientific-quality score. Viewing saved observations does not reverify scientific conclusions. User papers are not redistributed. Only the Skill version changes; its six reference instruction files remain unchanged.
