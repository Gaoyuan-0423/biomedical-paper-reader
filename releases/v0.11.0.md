# v0.11.0

## 中文

BioReader 中英界面与品牌更新预览版。按 **Pre-release** 发布，**v0.3.4** 继续保留为稳定版及 Latest。

- 顶部和设置新增「界面语言」，可在「简体中文」与「English」之间即时切换，覆盖文献库、阅读工具栏、问答、搜索、数据与复现、证据记录、Zotero、设置和操作提示。
- 语言偏好保存在本机，重启应用或桌面服务更换端口后仍可恢复。保存失败显示重试提示。
- 切换时保留未保存笔记、问答与表单草稿、输入焦点、选区及正在执行的任务。论文、标签、图注、笔记、模型回答和导出正文保持原语言；界面语言不修改模型提示词或生成语言。
- 统一书页与叶片品牌图案、浏览器图标和桌面应用图标。Go + MyGo 的原生下载、退出及错误提示提供中英文；原生文件选择器的系统按钮仍由操作系统决定。
- 继续使用 Go + MyGo 外壳与内置 Python 阅读服务，沿用原文引用、阅读导航和现有研究功能。

### 安装与更新

- Apple 芯片 Mac：[BioReader-v0.11.0-macos-arm64.dmg](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.11.0/BioReader-v0.11.0-macos-arm64.dmg)。打开 DMG，将 BioReader.app 拖入应用程序。
- Windows 10／11 x64：[安装 EXE](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.11.0/BioReader-v0.11.0-windows-x64-setup.exe)，或下载 [便携 ZIP](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.11.0/BioReader-v0.11.0-windows-x64.zip)，完整解压后运行 BioReader.exe，保留全部随附文件。

两平台无需另装 Python；Windows 需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。更新前退出旧版。macOS 数据仍在 `~/Library/Application Support/BioReader/`，Windows 仍在 `%LOCALAPPDATA%\BioReader`；替换程序保留论文、笔记和设置。程序包未进行 Apple Developer ID 公证或 Windows 代码签名。三份程序附件的校验值见同页 `SHA256SUMS.txt`。本版没有应用内自动升级或跨电脑文献库同步。

验证范围与最新原生 CI／产物验收状态见 [App 测试记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.11.0/app/tests/README.md)。已完成本轮工程回归与隔离浏览器交互检查；最终跨平台原生构建、安装与产物验收结果以本版 Release 的构建记录为准，浏览器检查不代替系统原生对话框验收。测试使用合成材料及模拟模型，未新增真实论文或科学解读质量评分。Skill 规则及六份 references 未变，仅更新版本。

## English

BioReader's bilingual interface and refreshed brand preview. This is a **Pre-release**; **v0.3.4** remains the stable Latest release.

- Choose Simplified Chinese or English in the header or Settings. Library, reading controls, chat, search, data and reproducibility, evidence, Zotero, settings and action messages update immediately.
- The language preference is saved on this computer and survives restarts or a changed desktop service port. A retry prompt appears if saving fails.
- Switching preserves unsaved notes, question and form drafts, input focus, selections and active tasks. Papers, tags, captions, notes, model answers and exported content retain their original language. Interface language does not change model prompts or the language of generated content.
- A book-and-leaf design now unifies the app brand, browser icon and desktop icon. MyGo download, exit and error prompts have Chinese and English text; system-owned file-picker buttons still follow the operating system.
- The Go + MyGo shell, bundled Python reading service, source links, reading navigation and existing research tools remain in place.

### Installation and updates

- Apple silicon Mac: download the [macOS arm64 DMG](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.11.0/BioReader-v0.11.0-macos-arm64.dmg), open it and drag BioReader.app to Applications.
- Windows 10/11 x64: use the [installer EXE](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.11.0/BioReader-v0.11.0-windows-x64-setup.exe), or extract the entire [portable ZIP](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.11.0/BioReader-v0.11.0-windows-x64.zip) and run BioReader.exe with all bundled files retained.

No separate Python installation is needed. Windows requires [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). Quit the old app before replacing program files. Papers, notes and settings stay in `~/Library/Application Support/BioReader/` on macOS and `%LOCALAPPDATA%\BioReader` on Windows. Packages are not Apple Developer ID notarized or Windows code-signed. `SHA256SUMS.txt` covers all three program assets. This release does not add in-app updates or library synchronization between computers.

See the [App validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.11.0/app/tests/README.md) for scope and the latest native CI and artifact checks. Engineering regressions and isolated browser interaction checks have completed. Refer to the build records for this release for final cross-platform native, installation and artifact checks; browser results do not establish acceptance of system-native dialogs. Tests use synthetic materials and simulated models, with no new real-paper or scientific interpretation quality assessment. Skill rules and all six reference documents are unchanged apart from the version label.
