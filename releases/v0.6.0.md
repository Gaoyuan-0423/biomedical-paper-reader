# v0.6.0

## 中文

BioReader 原文问答与引用定位预览版，作为 **Pre-release** 发布。保留蓝白界面和 v0.3.4 稳定版入口。

### 本次变化

- 在 PDF 中选中文字，直接解释、翻译或追问；选区记录对应文件与页码，取图模式继续用于裁图。
- 「问答」按论文保存对话，支持流式回答、停止、重新提问和加载较早历史，不覆盖精读笔记。
- 从本篇正文及补充 PDF 的相关文本片段回答；点击有效来源返回相应文件页码，有真实位置时高亮区域。引用文件被替换或移除时会提示。
- 超时、断流和输出长度限制会保留部分回答并标记未完成；输入草稿按论文暂存，迟到响应不会串到另一篇文献。
- 保留自动标签、结构化数据与复现表、GEO 样品补充和直接保存资源的流程。

### 下载与验证范围

下载 `BioReader-v0.6.0-macos-arm64.zip`，退出旧版后用解压出的 `BioReader.app` 替换。适用于 Apple 芯片 Mac，用户目录中的论文、笔记和设置保留。附件可用 `shasum -a 256 -c SHA256SUMS.txt` 校验。

测试采用隔离合成 PDF 与模拟模型，覆盖选择、问答历史、引用跳转、取消与失败恢复；没有调用真实付费模型，不宣称回答准确率。当前问答不纳入笔记导出，不支持扫描件 OCR 或整库语义检索。具体结果见[验证记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.6.0/app/tests/README.md)。原生 WebKit 本轮未重新验收，应用尚未进行 Apple 开发者签名或公证。

## English

This **Pre-release** adds source-grounded paper questions and PDF citation navigation. The blue-and-white workspace and stable v0.3.4 remain available.

### Changes

- Select PDF text to explain, translate or ask a question. Keep the selected file and page, with crop mode preserved for images.
- Save questions and answers independently per paper, with streaming, cancellation, retries and older-history loading. Reading notes remain separate.
- Use relevant text excerpts from the current paper and its supplements. Valid citations open the correct PDF page and highlight real text coordinates when available; changed or removed files are reported.
- Preserve partial output on timeouts, disconnects and output limits. Keep input drafts per paper within the window session and isolate late responses.
- Retain automatic tags, structured research resources, GEO sample metadata and direct resource saving.

### Download and validation scope

Download `BioReader-v0.6.0-macos-arm64.zip` for Apple silicon Macs, quit the old app and replace it with the extracted `BioReader.app`. Existing papers, notes and settings in the user directory are retained. Verify attachments with `shasum -a 256 -c SHA256SUMS.txt`.

Tests use isolated synthetic PDFs and mocked model responses; no paid model was called and no answer-accuracy claim is made. Questions are not included in note exports. This release does not add OCR or library-wide semantic search. See the [validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.6.0/app/tests/README.md). Native WebKit was not rechecked; the app has no Apple Developer ID signature or notarization.
