# v0.11.1

## 中文

BioReader 补充图图注修复版，对应 [Issue #29](https://github.com/Gaoyuan-0423/biomedical-paper-reader/issues/29)。按 **Pre-release** 发布，**v0.3.4** 继续保留为稳定版及 Latest。

- 修复补充图标题与图注正文字号不同，导致只提取到标题或短图注的问题。图注仍来自 PDF 文本，不通过模型猜写。
- 仅在相邻页的版面与文字样式可确认连续时补接跨页图注，遇到新图表或章节边界停止；扫描件和无法可靠关联的续页仍需人工对照。
- 已有记录需手动更新：**左侧 PDF 文件下拉框选择对应补充材料 → 图库 → 重新提取**。只处理当前选择的 PDF，不需要重新导入文件或重新生成笔记。
- 同一文件重提保留人工编辑的图注（包括主动清空）、读图观察、手动裁图、其他 PDF 的图片及原有图片 ID；已经插入笔记的图片引用继续有效。已有笔记和模型观察不会自动改写。
- 本次保持图号标签、原图页码和裁剪区域，沿用中英界面、书页与叶片图标及 Go + MyGo 与内置 Python 阅读服务。

### 安装与更新

- Apple 芯片 Mac：[BioReader-v0.11.1-macos-arm64.dmg](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.11.1/BioReader-v0.11.1-macos-arm64.dmg)。打开 DMG，将 BioReader.app 拖入应用程序。
- Windows 10／11 x64：[安装 EXE](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.11.1/BioReader-v0.11.1-windows-x64-setup.exe)，或下载 [便携 ZIP](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.11.1/BioReader-v0.11.1-windows-x64.zip)，完整解压后运行 BioReader.exe，保留全部随附文件。

两平台无需另装 Python；Windows 需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。更新前退出旧版。macOS 数据仍在 `~/Library/Application Support/BioReader/`，Windows 仍在 `%LOCALAPPDATA%\BioReader`；替换程序保留论文、笔记和设置。程序包未进行 Apple Developer ID 公证或 Windows 代码签名。三份程序附件的校验值见同页 `SHA256SUMS.txt`。本版没有应用内自动升级或跨电脑文献库同步。

图注提取、保留性回归及用户提供 PDF 的隔离检查范围见 [App 测试记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.11.1/app/tests/README.md)。最终跨平台原生构建、安装与产物验收以本版 Release 的构建记录为准，不将源码或提取测试等同于系统原生验收。本轮不调用真实模型，也没有新增论文精读或科学解读质量评分；不分发用户原始论文文件。Skill 规则及六份 references 未变，仅更新版本。

## English

BioReader supplementary caption fix, tracked in [Issue #29](https://github.com/Gaoyuan-0423/biomedical-paper-reader/issues/29). This is a **Pre-release**; **v0.3.4** remains the stable Latest release.

- Fixes captions truncated to their heading or first lines when supplementary figure headings and body text use different font sizes. Caption text comes from the PDF, without model-generated reconstruction.
- Continues captions across adjacent pages only when layout and text styles support the connection, stopping at new figures, tables or sections. Scans and uncertain continuation pages still require source review.
- To update existing records, **select the supplementary file in the PDF dropdown on the left → Figures → Re-extract**. This processes only the selected PDF. You do not need to re-import it or regenerate notes.
- Re-extraction of the same file preserves manually edited captions (including intentionally empty ones), observations, manual crops, figures from other PDFs and existing figure IDs. Images already inserted into notes keep their references; existing notes and model observations are not rewritten.
- Figure labels, source pages and crop regions remain unchanged. The bilingual interface, book-and-leaf icon, Go + MyGo shell and bundled Python reading service remain in place.

### Installation and updates

- Apple silicon Mac: download the [macOS arm64 DMG](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.11.1/BioReader-v0.11.1-macos-arm64.dmg), open it and drag BioReader.app to Applications.
- Windows 10/11 x64: use the [installer EXE](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.11.1/BioReader-v0.11.1-windows-x64-setup.exe), or extract the entire [portable ZIP](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.11.1/BioReader-v0.11.1-windows-x64.zip) and run BioReader.exe with all bundled files retained.

No separate Python installation is needed. Windows requires [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). Quit the old app before replacing program files. Papers, notes and settings stay in `~/Library/Application Support/BioReader/` on macOS and `%LOCALAPPDATA%\BioReader` on Windows. Packages are not Apple Developer ID notarized or Windows code-signed. `SHA256SUMS.txt` covers all three program assets. This release does not add in-app updates or library synchronization between computers.

See the [App validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.11.1/app/tests/README.md) for caption extraction, preservation regressions and isolated checks of the user-provided PDF. Final cross-platform native, installation and artifact results are recorded with this release; source and extraction tests do not establish system-native acceptance. This work does not call live models or add a new paper-reading or scientific interpretation quality assessment. The user's original paper files are not distributed. Skill rules and all six reference documents remain unchanged apart from the version label.
