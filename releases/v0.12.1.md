# v0.12.1

## 中文

修复读图后笔记消失与已有补充图图注未升级的问题。本版在双平台安装包验收后以正式 Release 和 Latest 发布。

- 新生成的精读、速读和读图解读跟随任务开始时的界面语言：英文界面生成英文，中文界面生成中文；切换界面不会改写已保存笔记。
- 图记录改为原子保存并保留有效备份，读取不会把写入中的文件当成空图库；不可恢复的损坏明确报错。
- 拒绝空白读图结果，保留已有观察。“全部读图”覆盖正文与补充材料的完整图，跳过已有结果；精读生成的图片预算仍单独生效。
- 每张图保存后即显示结果，元数据补全不再使正在执行的读图结果失效；断流、模型错误和刷新失败明确提示。
- 打开文献时自动升级旧版仅有编号的自动图注，保留手工图注、原图 ID、裁剪、读图观察和正文笔记。无需重新导入或重新生成精读笔记。
- 沿用图片左侧、Markdown 读图笔记右侧的查看器及中英文切换。已丢失且没有有效备份的观察无法凭空恢复；没有实际保存过的图仍需主动读图。

下载 [macOS ARM64 DMG](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.12.1/BioReader-v0.12.1-macos-arm64.dmg)、[Windows x64 安装 EXE](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.12.1/BioReader-v0.12.1-windows-x64-setup.exe) 或 [便携 ZIP](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.12.1/BioReader-v0.12.1-windows-x64.zip)。更新前正常退出所有位置的旧版，使用一个新版入口；用户数据保留在独立数据目录。Windows ZIP 需完整解压。发布页提供合并的 SHA256SUMS.txt。

测试使用合成资料与模拟模型，另在隔离副本中核对用户报告的旧补充图记录；私人论文不随源码分发。具体结果见 [App 验证记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.12.1/app/tests/README.md) 和本页的最终原生构建记录。未重新评测真实模型的科学解读质量。Mac 尚未做 Apple Developer ID 公证，Windows 尚未做发布者代码签名。

## English

Fixes disappearing saved figure observations and supplementary captions that were never upgraded in existing libraries. Publish this version as a regular Release and Latest after both native packages pass acceptance.

- New close/quick readings and figure observations follow the interface language captured when the task starts: English or Chinese. Switching the UI does not rewrite saved notes.
- Figure records use atomic saves and a valid backup. Reads no longer interpret a partially written file as an empty gallery; unrecoverable corruption produces an explicit error.
- Empty model responses cannot replace existing observations. Read all figures covers parent figures in both main and supplementary PDFs, skipping saved results. Close-reading generation retains its separate image budget.
- Each saved result appears during the batch. Metadata enrichment no longer invalidates an active reading task, and interrupted streams, model failures and failed refreshes report their status explicitly.
- Opening a paper upgrades legacy automatic label-only captions while preserving manual captions, IDs, crops, observations and paper notes. No reimport or note regeneration is required.
- Retains the image/Markdown viewer and bilingual UI. Lost observations without a valid backup cannot be reconstructed; figures without saved observations still require an explicit model reading.

Download the [macOS ARM64 DMG](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.12.1/BioReader-v0.12.1-macos-arm64.dmg), [Windows x64 installer](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.12.1/BioReader-v0.12.1-windows-x64-setup.exe) or [portable ZIP](https://github.com/Gaoyuan-0423/biomedical-paper-reader/releases/download/v0.12.1/BioReader-v0.12.1-windows-x64.zip). Quit old copies normally before updating and use one updated entry point. Libraries remain in their separate data directories. Extract the Windows ZIP completely. A combined SHA256SUMS.txt accompanies the packages.

Tests use synthetic fixtures and mocked models, plus isolated copies of the reported legacy supplementary records. Private papers are not redistributed. See the [App validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.12.1/app/tests/README.md) and final native-build evidence attached to this release. This release does not reassess live-model scientific quality. Apple Developer ID notarization and Windows publisher signing are not provided.
