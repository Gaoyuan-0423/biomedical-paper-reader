## 中文

在侧栏「编号 / 链接」粘贴文章网页或 PDF 直链，就能预览题录、加入当前课题库并查找正文。

- 可以混合输入网页、PDF 链接、DOI 和 PMID。即使网页地址中没有 DOI，也可通过页面公开的论文信息识别题录。确认前会显示题名、重复项与识别失败的链接。
- 点击「加入所选文献」后，链接条目会尝试获取缺少的正文。已有文献可以补齐 PDF，单独输入的 DOI 或 PMID 只导入题录。
- 批量操作按篇显示获取结果。遇到无法取得或需要核对的 PDF，可保留题录，单独重试该篇。也可以让队列在当前请求结束后停止。

桌面包提供 Apple 芯片 Mac DMG、Windows x64 安装 EXE 和便携 ZIP。三个文件的校验值见 SHA256SUMS.txt。

## English

Paste an article page or direct PDF URL in **IDs / Links** to preview the record, add it to the current project and look for the main PDF.

- Mix article pages, PDF links, DOIs and PMIDs in one preview. BioReader can identify papers from metadata on pages whose URLs contain no DOI. Review titles, duplicate entries and unrecognized links before confirming.
- Choose **Add selected papers** to look for missing full text for links. Existing records can receive a PDF. Standalone DOIs and PMIDs import metadata.
- Each link shows its download result. If a PDF is unavailable or needs review, the saved record remains available and its download can be retried individually. You can stop the queue after the current request.

Desktop packages include an Apple silicon macOS DMG, a Windows x64 installer and a Windows x64 portable ZIP. SHA256SUMS.txt lists the checksums for all three.
