# v0.17.0

## 中文

从 v0.16.1 升级后，可直接打开原有文献库的「库总览」，也能从论文问答中的补充表数值回到原始单元格。

- **按库整理笔记和插图**。选择一个文献库或「全部文献」，按已有标签筛选论文卡片。每张卡可展开背景、设计、方法、关键结果、机制、局限、课题启示和后续问题。插图画廊支持搜索图注、已存观察、作者和题名，点图可回到所属论文的 PDF 页。
- **导出离线网页**。将当前库的卡片、完整笔记和可用插图预览存为一个 HTML 文件，断网也能搜索和浏览。原始 PDF 可在 BioReader 内打开。
- **在补充表里查一个数**。在论文下添加 XLSX、CSV 或 TSV，在问答中给出行标识和指标，必要时再指定时间、分组或工作表。点击引用会打开原附件并高亮行和单元格。Excel 中受支持的数值格式随答案保留，点开来源可核对底层数值。查表在本机完成，无需模型 API Key。
- **把表格数值放进跨篇比较**。可带出处加入比较，标明实验组、参照组和指标尺度。统一方向时，已核对的 log2FC 可以同时查看原值和换算值。
- **查找和批量标签**。在正文或补充 PDF 中用 ⌘F 或 Ctrl+F 定位文字。也可给当前课题的筛选结果或搜索命中批量加标签，并撤销最近一次批量添加。

浏览器验收中，两篇测试论文的同名 `Table S2.xlsx` 分别返回 FLC 的 1.42（`DEGs!B8`）和 −0.73（`DEGs!C21`）。查询第二篇并刷新后，第一篇的历史引用仍打开它自己的 B8。[工程记录与测试入口](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.17.0/evals/runs/2026-11-28-v0.17.0/README.md)

Apple 芯片 Mac 下载 DMG。Windows 10/11 x64 可选安装向导 EXE 或便携 ZIP。三个程序包的校验值都在 `SHA256SUMS.txt` 中。[安装与更新说明](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.17.0/app/DESKTOP.md)

## English

Upgrading from v0.16.1 adds an overview to each existing library and lets you follow a supplementary-table answer back to its original cell.

- **Browse papers and figures by library.** Open a library or All papers and filter paper cards by existing tags. Expand a card to see up to eight sections from saved notes, including methods, results and limitations. Search the figure gallery by caption, saved observation, author or paper title. Open a figure's source to read the relevant PDF page.
- **Export an offline reading page.** Save the selected library's cards, full notes and available figure previews in a single searchable HTML file. Open the original PDFs in BioReader.
- **Look up one table value.** Attach an XLSX, CSV or TSV to a paper and ask for a row identifier and a metric. Add the time point, group or worksheet if necessary. A citation opens the original attachment with the source row and cell highlighted. Supported Excel number formats carry through to the answer, and the source preview shows the underlying number. Lookups run locally without a model API key.
- **Compare values across papers.** Add table values and their citations to a comparison and review the test group, reference group and measurement scale. For verified log2FC values, an optional common direction shows the converted value alongside the original.
- **Find text and tag papers.** Use ⌘F or Ctrl+F in the main or supplementary PDF. Bulk-add tags to filtered papers or library search results and undo the latest bulk addition in that project.

In the browser acceptance test, two papers had attachments named `Table S2.xlsx`. The first returned 1.42 for FLC at `DEGs!B8` and the second returned −0.73 at `DEGs!C21`. After querying the second paper and reloading, the first paper's saved answer still opened its own B8. [Test records and scripts](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.17.0/evals/runs/2026-11-28-v0.17.0/README.md)
