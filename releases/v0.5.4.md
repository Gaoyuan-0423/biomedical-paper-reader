# v0.5.4

## 中文

BioReader 简化资源保存预览版，作为 **Pre-release** 发布。保留蓝白界面、历史版本和 v0.3.4 稳定版入口。

### 本次变化

- 移除侧栏「筛选与待办」、待办数量和文献列表待办徽标；继续使用搜索、星标和标签筛选文献。
- 移除资源表及详情中的「待核对／已核对」标签与切换操作。编辑后点击「保存资源」即可，不再要求另行确认，也不再产生资源核对待办。
- 资源导出不再附核对状态；资源内容、来源位置及来源文件变化提醒保留，关键证据仍有独立核查状态。
- 历史资源字段兼容保留，人工修改和旧版已核对记录继续受到自动整理的保护。保留结构化表格、精读自动整理、GEO 样品补充和草稿保护。
- 笔记未完成、材料变化等实际问题仍在所属文献页面提示。

### 下载与验证范围

下载 `BioReader-v0.5.4-macos-arm64.zip`，退出旧版后用解压出的 `BioReader.app` 替换。适用于 Apple 芯片 Mac，用户目录中的论文、笔记和设置保留。`SHA256SUMS.txt` 可用于 `shasum -a 256 -c SHA256SUMS.txt` 核对附件。

验证覆盖资源保存、历史状态兼容、自动整理保护、无资源核对状态的导出、文献筛选、GEO 样品及浏览器布局。测试使用隔离合成文献与模拟 GEO 响应，没有调用真实付费模型。详细结果见[验证记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.5.4/app/tests/README.md)。原生 WebKit 本轮未重新验收，应用尚未进行 Apple 开发者签名或公证。

## English

This **Pre-release** simplifies resource saving and removes the library task interface. The blue-and-white workspace, earlier releases and stable v0.3.4 remain available.

### Changes

- Remove the sidebar task/filter section, task counts and paper-list task badges. Search, favorites and tag filters remain available.
- Remove pending/verified labels and selectors from resource rows and details. Editing and saving resources no longer requires a separate verification step or creates a verification task.
- Resource exports omit verification status while retaining content, source locations and source-change warnings. Evidence verification remains independent.
- Preserve legacy data fields, human edits and protection for previously verified records during extraction. Keep structured tables, deep-note extraction, GEO sample supplements and draft protection.
- Incomplete notes and material-change notices remain on their corresponding paper pages.

### Download and validation scope

Download `BioReader-v0.5.4-macos-arm64.zip` for Apple silicon Macs, quit the old app and replace it with the extracted `BioReader.app`. Existing papers, notes and settings in the user directory are retained. Verify attachments using `shasum -a 256 -c SHA256SUMS.txt`.

Validation covers saving, legacy-status compatibility, extraction protection, status-free resource exports, filtering, GEO samples and browser layouts. Tests use isolated synthetic papers and mocked GEO responses; no paid model was called. See the [validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.5.4/app/tests/README.md). Native WebKit was not rechecked; the app has no Apple Developer ID signature or notarization.
