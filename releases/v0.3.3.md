# v0.3.3

## 中文

本次是自最后正式发布 v0.2.0 以来的累计发布，覆盖 v0.3.0–v0.3.3 的技能改进，以及其后加入当前源码的 BioReader App、完整双语 README 和发布流程。CHANGELOG 中的日期记录开发修订时间，不代表这些版本曾分别发布到 GitHub Releases。

### 主要变化

- 完整精读逐张概览已有主图、补图和 Extended Data，再深入核查必要面板；新增逐图记录和查看动作校验，区分实际看图、仅读图注及读取障碍。
- 强化统计单位、证据边界、图文冲突复核与后续结果的方法解释；范围内每个结果单元均需解释问题、方法输入输出和论证衔接。
- 将阅读报告与过程记录分离，使报告聚焦研究问题、设计、科学含义和研究借鉴，同时保留可追溯工作记录。
- 重写技能入口、收敛重复规则，补充长论文增量笔记、可选 PDF 页渲染工具、自备论文评测协议、示例整理和 CI。
- 加入独立的 BioReader 本地应用：PDF 双栏解析与图注锚定取图、精读/速读流式笔记、图像解读、DOI 导入与相关文献，以及 Markdown、Word 和公众号复制导出。App 的安装、模型配置及依赖见 [App README](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.3.3/app/README.md)。
- README 提供完整中文与英文说明和语言跳转；增加版本一致性检查、手动发布工作流及维护指引。

### 验证范围与限制

历史验收按版本独立保留：v0.2.0 的语言/模式与附件更新；v0.3.0 的逐图动作和全补图回归；v0.3.1 的后续方法解释；v0.3.2 的报告与过程记录分离。v0.3.3 的工程与结构修订没有重跑行为试读。此次发布前的自动检查验证仓库链接、记录完整性、读取记录校验器、版本资料和脚本编译，不代表重新完成真实论文、全部视觉/语言流程或 App 端到端验收；未执行的原始数据分析也不算复现。

默认输出仍为中文完整精读，英文和中英双语需明确要求。补充材料默认只使用本地已有文件；只有明确要求补取才下载。技能本体与 App 相互独立，技能运行不新增固定 MCP、第三方技能或付费服务要求。

## English

This cumulative release covers changes since the last public release, v0.2.0: the v0.3.0–v0.3.3 skill improvements and the BioReader App, complete bilingual README, and release workflow subsequently added to the current source. Dates in CHANGELOG record development revisions; they do not mean that each version was separately published on GitHub Releases.

### Changes

- Full close reading inspects every available main, supplementary, and Extended Data figure before checking selected panels in detail. Figure reading records and viewing-action validation distinguish actual image inspection, legend-only reading, and access limitations.
- Stronger checks cover statistical units, inference limits, text–figure discrepancies, and method explanations for later results. Every result unit within scope must explain its question, methodological inputs and outputs, and role in the argument.
- Reading reports are separated from process records, keeping reports focused on research questions, design, scientific meaning, and ideas for future work while retaining traceable working records.
- The skill entry point was rewritten and repeated rules consolidated. Additions include incremental notes for long papers, an optional PDF page-rendering helper, an evaluation protocol for users' own papers, reorganized examples, and CI.
- The independent BioReader local app adds two-column PDF parsing, caption-anchored figure extraction, streaming close-reading/screening notes, figure interpretation, DOI import and related papers, and copying/export for Markdown, Word, and WeChat Official Accounts. See the [App README](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.3.3/app/README.md) for installation, model configuration, and dependencies.
- README now includes complete Chinese and English documentation with language navigation. Version-consistency checks, a manual publishing workflow, and release-maintenance instructions were added.

### Validation coverage and limitations

Historical evaluations remain version-specific: language/mode selection and supplement updates in v0.2.0; figure-viewing actions and all-supplement coverage regressions in v0.3.0; explanations of later methods in v0.3.1; and report/process-record separation in v0.3.2. The v0.3.3 engineering and structural revision did not rerun behavioral reading evaluations. Automated pre-release checks validate repository links, record integrity, the reading-record validator, version materials, and script compilation. They do not establish fresh end-to-end validation on real papers, across all visual/language workflows, or for the App. Raw-data analyses that were not run are not claimed as reproduced.

Full close reading in Chinese remains the default; English and Chinese–English bilingual reports require an explicit request. Supplementary materials are taken from local files by default and downloaded only when explicitly requested. The skill and the App are independent; using the skill adds no requirement for fixed MCP servers, third-party skills, or paid services.
