# v0.9.0

## 中文

BioReader 对照阅读与问答摘录预览版，作为 **Pre-release** 发布。保留 v0.3.4 稳定版。

### 本次变化

- 增加 Windows 10 / 11 x64 便携程序包，与 macOS arm64 从同一检查过的源码提交构建，以同一版本发布。Windows 用户数据独立保存在 `%LOCALAPPDATA%\BioReader`。
- 顶部增加「专注原文」「笔记对照」「边读边问」。宽窗口可展开原文或并排查看笔记／问答；窄窗口继续使用单面板切换。正文与补充 PDF 保留连续滚动、缩放和阅读位置。
- 问答支持 Markdown 标题、列表、表格与代码块，保留来源按钮；不执行回答中的 HTML 或加载远端图片。引用仍在校验来源文件版本后跳转，有可靠坐标时高亮原文。
- 快捷问题围绕当前页或选区，点击填入后可修改并手动发送。回答使用有界的相关原文片段，不把局部问答称为全文精读。
- 已完成回答可复制为 Markdown，或连同来源文件名、PDF 页码和原文摘录追加到现有笔记。保留已有编辑内容，同一回答重复追加会去重；保存失败时保留草稿，可重试保存。未完成回答不能追加为完整摘录。
- 阅读交互参考作者的 BohrReader 项目，按 BioReader 现有结构独立实现。保留蓝白界面、星标、自动与手动标签、结构化样品资源、全库本地搜索和 Zotero MCP 导入。

### 安装与验证范围

按系统选择预览附件，以本页实际提供的文件为准：

- Apple 芯片 Mac：`BioReader-v0.9.0-macos-arm64.zip`，退出旧版后替换 `BioReader.app`。
- Windows 10 / 11 x64：`BioReader-v0.9.0-windows-x64.zip`，完整解压后打开文件夹中的 `BioReader.exe`，保留 `_internal` 等全部随附文件。需要 Microsoft Edge WebView2 Runtime，缺少时安装[微软官方 Evergreen Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。

用户目录中的论文、笔记和设置保留：macOS 为 `~/Library/Application Support/BioReader/`，Windows 为 `%LOCALAPPDATA%\BioReader`。程序需退出后再更新，Windows 应完整解压新版，不只替换 exe。同页 `SHA256SUMS.txt` 列出两个 ZIP 的校验值；macOS 使用 `shasum -a 256`，Windows 使用 PowerShell `Get-FileHash -Algorithm SHA256` 计算并比较已下载文件的值。

两平台按同一版本更新；用户通过下载新包更新程序。本版没有应用内自动更新器或跨电脑文献库同步，模型和 Zotero 设置仍在每台电脑独立配置。

快捷问题使用现有模型设置，发送后才调用模型。阅读布局、历史查看、复制和追加已有回答本身不调用模型。问答摘录保留回答当时的来源快照，不自动核实科学结论；全文精读继续使用「生成笔记」。此版未引入 BohrReader 的自主工具执行流程或跨论文 AI 任务。

本版不改变 skill 的阅读规则，`SKILL.md` 仅更新版本，六份 references 保持不变。实际自动回归、浏览器交互与打包结果见[验证记录](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.9.0/app/tests/README.md)。合成材料和模拟回答不等于真实模型或科学解读质量评测；原生 WebKit、Windows WebView2 与各系统保存对话框的验收范围以该记录为准，构建成功不等于所有目标系统的完整界面验收。应用未进行 Apple 开发者签名或公证。

## English

This BioReader **Pre-release** improves reading alongside notes and chat, and saving useful answers into notes. Stable v0.3.4 remains available.

### Changes

- Add a portable Windows 10 / 11 x64 package alongside macOS arm64, built from the same checked source commit and released under the same version. Windows user data is stored separately in `%LOCALAPPDATA%\BioReader`.
- Add focused PDF, notes comparison and reading-with-chat layouts in the top bar. Wide windows can expand the PDF or show notes/chat alongside it; narrow windows retain single-pane switching. Main and supplementary PDFs keep continuous scrolling, zoom and saved reading positions.
- Render Markdown headings, lists, tables and code blocks in answers while retaining source buttons. Answer HTML is not executed and remote images are not loaded. Source navigation still checks the file revision and highlights the original text when reliable coordinates exist.
- Offer question starters for the current page or selection. Clicking inserts an editable question for manual sending. Answers use bounded relevant source excerpts and do not claim a full-paper close reading.
- Copy completed answers as Markdown or append them with source file names, PDF pages and original quotations to existing notes. Preserve current edits, deduplicate repeated appends of the same answer, and keep the draft if saving fails so it can be retried. Incomplete answers cannot be appended as completed excerpts.
- Reading interactions draw on the author's BohrReader project and are independently implemented within BioReader. Keep the blue-and-white workspace, favorites, automatic/manual tags, structured sample records, local library search and Zotero MCP imports.

### Installation and validation scope

Choose the preview asset for your platform from the files actually published on this page:

- Apple silicon Mac: `BioReader-v0.9.0-macos-arm64.zip`; quit the old app before replacing `BioReader.app`.
- Windows 10 / 11 x64: `BioReader-v0.9.0-windows-x64.zip`; extract the entire folder and open `BioReader.exe`, retaining `_internal` and all bundled files. Microsoft Edge WebView2 Runtime is required; install the [official Evergreen Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) if missing.

Existing papers, notes and settings stay in the user data directory: `~/Library/Application Support/BioReader/` on macOS and `%LOCALAPPDATA%\BioReader` on Windows. Quit the app before updating; on Windows extract the complete new package rather than replacing only the exe. `SHA256SUMS.txt` lists both ZIP hashes. Calculate the downloaded file's hash with `shasum -a 256` on macOS or PowerShell `Get-FileHash -Algorithm SHA256` on Windows and compare it with the matching entry.

Both platforms follow the same release version. Users update by downloading the new package; there is no in-app updater or cross-device library sync. Model and Zotero settings remain separate on each computer.

Question starters use the existing model settings and call the model only after sending. Changing layouts, reading history, copying and appending existing answers do not themselves call a model. Excerpts retain the source snapshot from the original answer without certifying its scientific conclusions. Full close reading continues through note generation. This release does not introduce BohrReader's autonomous tool execution or cross-paper AI tasks.

The skill's reading rules are unchanged: only the version in `SKILL.md` is updated, and all six reference files are preserved. See the [validation record](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.9.0/app/tests/README.md) for actual regressions, browser interactions and build results. Synthetic materials and mocked answers do not assess real-model or scientific reading quality; consult that record for native WebKit, Windows WebView2 and platform save-dialog acceptance. A successful build is not full GUI acceptance on every target system. The app has no Apple Developer ID signature or notarization.
