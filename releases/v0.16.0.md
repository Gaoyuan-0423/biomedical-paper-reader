# v0.16.0

## 中文

本页记录 v0.16.0 的发布草稿。Windows 桌面验收在 Zotero 迁移测试读取 SQLite 的共享内存文件时失败，原标签保留。完整功能随 v0.16.1 交付。[当次 Windows 验收](https://github.com/Gaoyuan-0423/biomedical-paper-reader/actions/runs/44747754562/job/136327416797) · [v0.16.1 发布说明](v0.16.1.md)

在「课题库 → 跨篇比较」输入研究问题、勾选至少两篇论文，点「为勾选的论文起草比较表」。可选入组人数、完整配对人数、实际进入单细胞分析的人数和取样部位。

- **跨篇比较**。先复用已保存的证据卡和字段摘录；仍有空格时，可点「从正文和补充 PDF 补查缺项」。每个候选都有文件、页码和原句，另列每份 PDF 的已查与未查页数、无可读文字的页码。发现和验证队列分别列出；遇到指向补表的原句时，提示查找缺件或核对已存附件。打开原文后逐格采纳、修改或跳过，保存后仍可重开人工判断和来源。
- **报告复核**。在报告中选中一句话，点「核对这句话」查看邻近引文、候选图表、方法与干预相关摘录。选定依据、填写判断和修订用语后保存。「本次读图」区分生成该报告时各张正文图、补图的视觉观察、仅用图注、未处理及失败情况。可补读单图、手动补入漏提取的图。
- **阅读快捷操作**。批量导入后「为这几篇补正文」，读图后「记为证据」，保存的证据卡可「加入当前比较」。同一篇示例论文的三张操作截图展示了从补图找到对照、保存原句和引用这条证据的过程。[操作图示](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.16.0/README.md)
- **PubMed 追踪**。首次检查最近 7 天收录的记录。以后启动时，距成功检查已满 24 小时的检索式会从上次进度补查，失败保留进度，归档课题或暂停的检索式会跳过。未看列表按 PMID 去重，每页最多 50 篇，可单页预览、选择导入或标记已看。
- **组会 PPTX**。从课题收藏图表选图、排序，逐页填写英文研究问题、关键对照、观察和局限，另附中文讲者备注。配置模型后可从选中图的图注和已存观察起草双语内容，逐字段核查引用和修改。导出的幻灯片可以编辑，页脚保留论文、图号和 PDF 页码。
- **本机 Zotero 迁移**。在 Zotero 入口选择「从本机 Zotero 文库迁移」。预览题录、子笔记、本机已存 PDF 和重复项后，选择所需材料加入课题。此入口使用本地数据库快照，可直接用于一次性迁移。
- **检索性能与 Rust**。128 篇合成论文、已有文字缓存的整库无命中查询，中位耗时从 240.4 毫秒降至 97.3 毫秒，同条件 Rust 原型为 101.0 毫秒。不同查询的结果及冷提取测试详见记录。发行版采用 Python 标准库匹配，Rust 原型可独立复跑。[测量条件与结果](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.16.0/app/tests/README.md) · [复跑方法](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.16.0/evals/benchmarks/README.md)

桌面包提供 Apple 芯片 Mac DMG、Windows x64 安装 EXE 和便携 ZIP。三个文件的校验值见 SHA256SUMS.txt。

## English

These are the original draft notes for v0.16.0. The Windows desktop validation failed when the Zotero migration test tried to read SQLite’s shared-memory file. The original tag is retained. See the complete feature list for v0.16.1. [Windows validation](https://github.com/Gaoyuan-0423/biomedical-paper-reader/actions/runs/44747754562/job/136327416797) · [v0.16.1 release notes](v0.16.1.md)

In a project's **Compare papers** view, enter a question, select two or more papers and choose **Draft a table for selected papers**. Available columns cover enrollment, participants with complete pairs, participants in single-cell analysis and sampling sites.

- **Cross-paper comparisons.** Start with saved evidence cards and field excerpts. To fill gaps, choose **Find missing fields in main and supplementary PDFs**. Each candidate identifies the file, PDF page and quotation. Coverage lists pages examined, pages skipped and pages without readable text. Explicit discovery and validation cohorts appear separately. A pointer to a supplementary table shows whether to look for a missing attachment or check one already saved. Open the source, then accept, edit or skip each cell.
- **Report review.** Select a sentence and choose **Review this claim**. Inspect nearby citations, candidate figures and captions, methods and possible intervention excerpts. Save your evidence, assessment and revised wording. **Figure coverage** records the material supplied for each main and supplementary figure at generation time, including caption-only inputs, unprocessed figures and failed visual reads. Read a figure again or capture a figure the extractor missed.
- **Reading shortcuts.** Get full text for a batch just imported, save a figure reading as evidence, and add an evidence card to the current comparison. Three screenshots follow the same synthetic paper from checking a supplementary figure to citing a quotation. [Walkthrough](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.16.0/README.md)
- **PubMed tracking.** The first search covers the past seven days by PubMed creation date. Startup checks resume from the last successful search after 24 hours. Failures preserve the checkpoint. Paused searches and archived projects are skipped. Preview, import and mark unread PMIDs as seen in pages of up to 50.
- **Journal club slides.** Select and order saved figures, edit English questions, controls, observations and limitations, and add Chinese speaker notes. A configured model can draft missing fields from the selected figure’s caption and saved observations. Review the quoted support before exporting. Export an editable PPTX with the paper, figure and PDF page in each footer.
- **Local Zotero migration.** Open the local migration option under Zotero to preview bibliographic records, child notes, stored PDFs and duplicates. Select the materials to add to the project from a local snapshot of the Zotero database.
- **Search performance and Rust.** On 128 generated papers with cached text, the median end-to-end time for an exhaustive no-match search fell from 240.4 ms to 97.3 ms. The Rust prototype took 101.0 ms under the same conditions. The desktop release uses the Python standard-library matcher. [Results and measurement conditions](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.16.0/app/tests/README.md) · [Reproduce the benchmark](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.16.0/evals/benchmarks/README.md)

Desktop packages include an Apple silicon macOS DMG, a Windows x64 installer and a portable ZIP. SHA256SUMS.txt lists the checksums for all three.
