# v0.16.0

## 中文

打开课题库的「跨篇比较」，填入研究问题，勾选至少两篇论文，然后点「为勾选的论文起草比较表」。可选入组人数、完整配对人数、实际进入单细胞分析的人数和取样部位四列。

- 草稿复用已保存的证据卡与字段摘录。每个候选值都附有文件、页码和原句。点「查看原句」打开对应 PDF，核对后可逐格采纳、修改或跳过。保存比较后可以重开已采纳的值及出处。
- 原句明确写出发现队列或验证队列时，各队列分别显示。遇到指向缺失补表的摘录时，界面提示补查。其他缺项显示「已保存的材料中未找到」。
- 在同一课题已有比较问题时，打开论文的证据卡，点「加入当前比较」，回到比较页保存即可。README 用同一篇合成论文的三张实操截图展示从补图查对照、保存原句到在比较中引用的过程。[图示](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.16.0/README.md)
- 全库检索对已有文字缓存的论文使用更快的文本匹配。测试了 5 篇和 128 篇原创合成 PDF，还比较了 Rust 原型的端到端耗时。桌面版使用 Python 标准库实现。[基准与复跑方法](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.16.0/evals/benchmarks/README.md)

桌面包提供 Apple 芯片 Mac DMG、Windows x64 安装 EXE 和便携 ZIP。三个文件的校验值见 SHA256SUMS.txt。

## English

Open **Compare papers** in a project, enter a research question, select at least two papers and choose **Draft a table for selected papers**. Select participant enrollment, participants with complete pairs, participants in single-cell analysis, or sampling sites.

- Candidates come from saved evidence cards and field excerpts. Each has a file, page and quotation. Open the cited page to review a candidate, then accept, edit or skip the cell. Save the comparison to reopen accepted values with their sources.
- Explicit discovery and validation cohort labels are kept separate. The table flags excerpts that refer to a missing supplementary table. Other gaps read **Not found in saved material**.
- Once a comparison has a question, open an evidence card from the same project and choose **Add to current comparison**. Save the comparison to keep the reference. Three screenshots follow the same synthetic paper from checking a supplementary figure through saving a quotation to citing it in a comparison. [Walkthrough](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.16.0/README.md)
- Library search matches text faster when PDF text blocks are already cached. End-to-end measurements used 5 and 128 generated PDFs and included a Rust prototype. The desktop application uses the Python standard library implementation. [Benchmark and reproduction steps](https://github.com/Gaoyuan-0423/biomedical-paper-reader/blob/v0.16.0/evals/benchmarks/README.md)

Desktop packages include an Apple silicon macOS DMG, a Windows x64 installer and a portable ZIP. SHA256SUMS.txt lists the checksums for all three.
