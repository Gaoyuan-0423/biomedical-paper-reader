# v0.4.0

## 中文

本版基于已发布的 v0.3.4，增加 BioReader macOS 独立桌面窗口和可下载的 Apple 芯片 Mac 预览包。GitHub Release 标记为 **Pre-release**；桌面 GUI 仍有待验收项，v0.3.4 稳定版保留。论文阅读行为规则没有改动。

下载与安装：

1. 下载本页附件 `BioReader-v0.4.0-macos-arm64.zip`，适用于 Apple 芯片 Mac（arm64）。本次不提供 Intel Mac、Windows 或 Linux 安装包。
2. 解压后，将 `BioReader.app` 拖入“应用程序”或从解压目录直接打开。更新前先退出旧版 App；无需另装 Python 或手动启动浏览器／终端。
3. 可将附件 `SHA256SUMS.txt` 与 ZIP 放在同一目录，运行 `shasum -a 256 -c SHA256SUMS.txt` 检查下载完整性。

主要变化：

- 独立 macOS 窗口、应用图标和 PyInstaller 构建脚本；Python、后端与前端资源随 App 打包，关闭窗口时停止本机后台。
- 论文、笔记和设置保存在 `~/Library/Application Support/BioReader/`，替换 App 不会删除这些数据。原网页版的 `app/data/` 不会自动迁移，请先备份再按桌面说明迁移。
- PDF.js、Marked、Highlight.js、docx、字体与 CMap 使用本地资源，并保留第三方许可证。AI 模型、DOI 和相关文献查询仍需联网；AI 功能需要自行配置可用接口和 API Key。
- 本机服务监听随机回环端口，检查 Cookie、Host、Origin 与 Fetch Metadata；多窗口使用独立会话 Cookie，并启用桌面文件下载。

验证与限制：

- 29 项阅读记录、发布元数据和桌面回归以及仓库完整性检查通过；实际 arm64 编译包通过应用包完整性、Info.plist、启动、本地资源、会话／来源限制、PDF 上传／下载／删除与笔记持久化检查。接口验证使用独立临时数据目录。
- 窗口内 PDF 显示、macOS 保存对话框、Word 导出和真实 AI 生成仍待人工验收，由 [Issue #6](https://github.com/Gaoyuan-0423/biomedical-paper-reader/issues/6) 跟踪。未重跑真实论文试读，不将接口检查或 CI 通过视为 GUI 端到端验收。
- 预览包未做 Apple 开发者签名或公证，macOS 可能阻止首次打开；本机包完整性检查不代表 Apple 公证或其他 Mac 的安装验收。

## English

Based on the published v0.3.4, this version adds a standalone BioReader macOS window and a downloadable preview bundle for Apple silicon Macs. This GitHub Release is a **Pre-release** with outstanding desktop GUI acceptance tests; the stable v0.3.4 remains available. Paper-reading behavior rules are unchanged.

Download and install:

1. Download the `BioReader-v0.4.0-macos-arm64.zip` asset for Apple silicon Macs (arm64). This release does not include Intel Mac, Windows, or Linux installers.
2. Extract the ZIP, then move `BioReader.app` to Applications or open it from the extracted directory. Quit an older instance before updating. No separate Python installation, browser, or manual backend startup is required.
3. Optionally download `SHA256SUMS.txt` beside the ZIP and run `shasum -a 256 -c SHA256SUMS.txt` to check download integrity.

Changes:

- A standalone macOS window, application icon, and PyInstaller build script bundle Python, the backend, and frontend resources. Closing the window stops the local service.
- Papers, notes, and settings live in `~/Library/Application Support/BioReader/`, outside the replaceable application bundle. Existing web-app data under `app/data/` are not migrated automatically; back up first and follow the desktop guide.
- PDF.js, Marked, Highlight.js, docx, fonts, and CMaps use bundled resources with third-party licenses retained. AI, DOI lookup, and related-paper searches still require network access; AI requires a configured model endpoint and API key.
- The service listens on a random loopback port and checks cookies, Host, Origin, and Fetch Metadata. Concurrent windows use separate session cookies, and desktop file downloads are enabled.

Validation and limits:

- All 29 reading-record, release-metadata, and desktop regression tests and repository integrity checks pass. The actual arm64 bundle passed bundle-integrity, Info.plist, startup, local-resource, session/origin, PDF upload/download/delete, and note-persistence checks using an isolated temporary data directory.
- In-window PDF rendering, macOS save dialogs, Word export, and live AI generation still need manual acceptance testing, tracked in [Issue #6](https://github.com/Gaoyuan-0423/biomedical-paper-reader/issues/6). Real-paper reading trials were not rerun; interface checks and CI do not establish end-to-end GUI acceptance.
- The preview bundle has no Apple Developer ID signature or notarization, so macOS may block its first launch. Local bundle-integrity checks do not establish Apple notarization or installation compatibility with other Macs.
