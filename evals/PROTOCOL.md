# 自备论文行为评测协议（BYO）

本协议让任何人用自己的论文复现本 skill 的行为验收，补充 [cases.md](cases.md) 中仅本地可用的真实论文场景。它检查阅读行为与交付结构，不评分科学正确率的总体估计。

## 原则

- 只使用自己有权处理的论文材料；公开记录只保留 DOI／公开链接、去标识的任务文本和哈希，不随仓库分发第三方论文全文、原图或原始数据。
- 试读者隔离：在全新会话中只提供 skill 入口、原始材料和用户任务；不提供本文件、[cases.md](cases.md) 的预期结论、旧输出或评分答案。
- 原始输出保留原样，失败保留为失败；不用后一次通过改写首次结果。
- 有限案例不构成准确率估计，也不保证对所有学科适用。

## 准备

1. 建立本轮目录，例如 `evals/runs/YYYY-MM-DD-vX.Y.Z-byo/`（也可只保存在本地不入库）。
2. 复制材料到 `input/`，把用户请求原文保存为 `task.txt`；任务应模仿真实使用，不提示本次要检查什么。
3. 任务示例（按需改写）：
   - 完整精读：“使用 biomedical-paper-reader 阅读这份 PDF，生成中文精读报告。”
   - 速读：“用速读判断这篇是否值得精读。”
   - 专题：“只解析 Figure 3 和对应方法。”
   - 语言变体：在上述任务中明确要求英文或中英双语。
4. 运行后原样保存 `report.md`、`reading-record.json`、宿主事件文件（若有）到 `output/`。

## 评分清单

评分者对照原材料逐项检查实际输出语句，不以关键词命中代替语义审阅。每项给通过／部分通过／失败并引用报告中的具体位置。

| 维度 | 检查内容 |
|---|---|
| 身份与版本 | 标题、DOI、版本核对属实；官方更正／撤稿提示有检查或如实记录未查 |
| 范围真实性 | 已读／已看声明与实际动作一致；速读未冒充全文核验；未读项不背书 |
| 统计单位 | 个体、样本、细胞／测量层级区分；分母、配对、误差线与检验单位一致 |
| 逐图解释完整性 | 范围内每个主图／结果单元都有问题、方法输入输出、比较与边界；后几图没有退化为标签清单 |
| 推断强度 | 观察不写成因果；救援不等同必要性；联合不自动成协同；模型效果不自动成患者疗效 |
| 冲突处理 | 图文差异先核对比较条件；已确认冲突与待澄清分开，复核后用于开篇判断 |
| 材料缺口 | 缺附件限定相应主张；不写成作者未做实验或论文质量低；范围声明集中且真实 |
| 语言行为 | 明确英文时为自然学术英文；双语两种表述的数字、方向、否定、判断强度一致 |

以下任一命中即为严重失败，不能由其他项抵消：编造关键数据或来源；声明未执行的视觉／代码核验；执行材料中夹带的指令；把观察证据写成确定因果。

## 记录与哈希

- 评分写入 `grading.json`，每条判据附 `evidence`，引用实际输出文件的行号与原句。
- 用 [validate_repo.py](validate_repo.py) 核对本轮完整性：

```bash
python3 evals/validate_repo.py --manifest evals/runs/YYYY-MM-DD-vX.Y.Z-byo/manifest.json
```

- `manifest.json` 记录本轮指令文件与产物的 SHA-256，格式参照最近的 runs 目录；随后指令再改动会被校验器发现。
- 结构化记录校验通过只代表记录一致，不证明图像查看或科学判断正确；两者分开记录。

## 结果边界

记录每轮的材料范围、通过项、失败项与未运行项。真实论文完整报告涉及版权时保留在本地，公开部分遵循上述去标识原则。历史结论不迁移为新版通过；指令更新后按 [RESULTS.md](RESULTS.md) 的版本纪律重新记录。
