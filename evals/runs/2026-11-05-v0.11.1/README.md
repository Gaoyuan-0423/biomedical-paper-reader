# v0.11.1 补充图图注修复验证范围

本轮改变 PDF 图注提取，解决标题与正文字号不同时正文过早截断的问题，并对版面连续性明确的跨页图注保守续接。`SKILL.md` 仅更新版本，六份 references 保持 v0.11.0 内容；当前指令哈希见 [manifest](manifest.json)。`cases: []` 表示没有新增论文精读报告或科学解读质量评分。

验证重点包括字号变化、跨页续接及停止边界、已有短图注重新提取，以及人工图注、读图观察、手动裁图、正文／补充文件隔离、原图片 ID 与笔记引用的保留。本次保持图号标签、页码和裁剪区域，避免将图注修复变成图片身份迁移；已经生成的笔记和模型观察不会自动重写。

合成夹具回归、用户提供 PDF 的隔离提取检查及实际结果统一见 [App 验证记录](../../../app/tests/README.md)。检查图注提取不代表重跑论文精读、视觉证据审查或科学质量评测；不在公开仓库分发用户原始论文文件。

桌面架构仍为 Go + MyGo 与内置 Python 阅读服务。最终跨平台原生构建、安装与产物验收以同版 Release 构建记录及 [App 验证记录](../../../app/tests/README.md) 为准，不把源码或提取测试等同于系统原生验收。
