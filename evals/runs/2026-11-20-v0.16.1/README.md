# v0.16.1 工程验收

本次记录的日期为 2026-11-20。自 v0.15.0 以来的交付包括跨篇比较和 PDF 补查、报告选句复核和读图覆盖、阅读快捷操作、PubMed 增量追踪、组会 PPTX、本机 Zotero 迁移以及缓存检索优化。[完整双语说明](../../../releases/v0.16.1.md)

### 功能核查

五篇合成论文中，20 个比较字段里有 17 个有直接依据，17 个候选的值和出处与预设相符。3 个缺少已存依据的字段留空。该核查、桌面阅读流程截图及 Python 与 Rust 的测量均来自 v0.16.0 的工程验收。真实读者完成核查所需时间、修改率和引文支持程度尚待实读评测。[原始验收记录](../2026-11-20-v0.16.0/README.md) · [检索基准](../../benchmarks/README.md)

### Windows 上的本机 Zotero 文库

v0.16.0 的 Windows 桌面任务在测试读取活跃文库的 SQLite 共享内存文件时失败。v0.16.1 的测试在导入前后比对主库和 WAL 文件的大小、修改时间及 SHA-256，另比对共享内存文件的存在、大小与修改时间。Windows 上若源数据库被独占锁定，界面会提示退出 Zotero 再试。Windows 专属回归在源库加锁时检查这一提示，解锁后重新预览。本机 macOS 运行该模块通过 5 项，系统专属用例按条件跳过。[原任务日志](https://github.com/Gaoyuan-0423/biomedical-paper-reader/actions/runs/44747754562/job/136327416797) · [Zotero 迁移回归测试](../../../app/tests/test_zotero_local.py)
