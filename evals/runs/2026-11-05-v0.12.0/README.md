# v0.12.0 读图笔记查看器验证范围

本轮新增图库中的图像／读图笔记查看器，展示每张图已保存的完整观察，独立于论文正文笔记。打开已有结果不重新调用模型，不要求重新提取、重新读图或重新生成笔记。`SKILL.md` 仅更新版本，六份 references 保持 v0.11.1 内容；当前指令哈希见 [manifest](manifest.json)。`cases: []` 表示没有新增论文精读报告或科学解读质量评分。

验证关注缩略图与「查看笔记」入口、完整 Markdown、原图注、无观察的空态、图像缩放、宽窄窗口布局及独立滚动；还应确认查看既有结果不会写入正文笔记或触发模型请求。安全边界包括 HTML、危险链接、Markdown 内嵌图片及内部伪引用，左侧图像应由当前文献的本地图记录提供。

回归与隔离浏览器交互的实际结果统一见 [App 验证记录](../../../app/tests/README.md)。合成观察用于验证显示与操作，不代表模型科学判断正确，也不代表重新核查了原图。公开仓库不分发用户原始论文文件。

桌面架构继续采用 Go + MyGo 与内置 Python 阅读服务。最终 macOS／Windows 原生构建、安装与产物验收以同版 Release 构建记录及 App 验证记录为准，不把源码或浏览器测试当作原生验收，不预填尚未执行的结果。
