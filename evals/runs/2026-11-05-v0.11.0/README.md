# v0.11.0 中英界面与品牌更新验证范围

本轮改变 App 界面语言、偏好存储、品牌图标与原生操作提示。`SKILL.md` 仅更新版本，六份 references 保持 v0.10.0 内容；当前指令哈希见 [manifest](manifest.json)。`cases: []` 表示没有新增真实论文试读或科学解读评分。

已完成的工程回归覆盖界面语言切换、磁盘偏好、原始内容与未保存输入保护、活动任务和原生文案选择；隔离浏览器验证覆盖主阅读界面和研究工作流，并检查模拟流式生成期间切换语言，以及服务端口改变后使用全新浏览器配置恢复语言。实际执行结果与数量集中记录于 [App 验证记录](../../../app/tests/README.md)。测试使用合成材料、模拟模型与隔离文献库，没有读取私人论文库或调用私人 API Key。

界面切换不修改模型提示词、输出语言或论文、标签、笔记及研究记录中的原始文本；本轮工程结果不能解释为自动翻译质量或科学解读质量提升。

桌面架构仍为 Go + MyGo 与内置 Python 阅读服务。跨平台原生 CI、安装与发布产物验收分别记录；最终结果以同版 Release 的原生构建记录及 [App 验证记录](../../../app/tests/README.md) 为准。浏览器检查或原生文案单元测试不能替代 macOS／Windows 系统对话框验收。
