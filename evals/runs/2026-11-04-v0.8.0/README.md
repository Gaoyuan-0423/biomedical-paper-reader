# v0.8.0 样品整理与全库检索工程验证

日期：2026-11-04。范围：7 个样品结构字段、明确标签与表格列整理、旧自动记录兼容与备份保护、组合筛选、资源 CSV／编号 TXT 导出、本机正文／补充 PDF／已保存笔记检索，以及结果来源定位。

`SKILL.md` 仅更新版本，六份 references 与 v0.7.0 哈希一致；Skill 的论文阅读行为规则未改。App 的精读提示词新增样品标签格式，要求按原文保留样本单位与各队列数量，不能拿 GEO 收录量代替论文实际使用量。当前指令哈希见 [manifest](manifest.json)。`cases: []` 表示没有新增真实论文试读或科学质量评分，工程回归不代表模型提取准确率评测。

功能组织参考 [BiblioCell](https://github.com/xuzhougeng/BiblioCell) 的数据整理与检索思路，使用 BioReader 的原有结构独立实现，没有复制上游代码或素材。本轮只覆盖当前明确实现的功能，不包含文献定时跟踪、开放全文获取、BibTeX、备份／恢复界面、对外 MCP 服务、OCR、语义检索或跨论文 AI 问答。

验证使用隔离合成 PDF、笔记和资源记录，不读取私人文献库或调用真实模型。检查关注原始样品说明与分组保留、人工字段保护、GEO 与论文用量分离、筛选与导出一致、公式前缀保护、明确编号去重、搜索范围与分页、过期来源拒绝、PDF 页定位和笔记打开。旧 PDF 首次建本地文本缓存可能较慢；笔记结果不承诺句内定位。

自动回归、真实浏览器与构建的实际结果统一记录于 [App 验证记录](../../../app/tests/README.md)。原生 WebKit 本轮未重新验收；应用仍无 Apple 开发者签名或公证。
