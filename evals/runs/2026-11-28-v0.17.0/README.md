# v0.17.0 工程验收

本次工程验收使用合成论文、补充表和临时文献库。自动化浏览器在独立桌面服务中运行。科学阅读评测仍沿用前次记录，本版没有新增科学评分样本。

- 两个文献库各含两篇，一篇共享。「全部文献」显示三篇。两篇都标为 Fig 1 的插图分别回到各自论文和页码。导出其中一个库，断网后可搜索本库、读完整笔记、查看内嵌插图。[浏览器验收](../../../app/tests/browser_library_digest.py)
- 两篇论文各挂一份 `Table S2.xlsx`。第一篇的 FLC log2FC 为 1.42（`DEGs!B8`），第二篇为 −0.73（`DEGs!C21`）。查完第二篇、重载页面、打开第一篇的历史引用，仍定位到第一篇的 B8 并显示 1.42。保存并重开跨篇比较也保留两处原表引用。[浏览器验收](../../../app/tests/browser_table_citations.py)
