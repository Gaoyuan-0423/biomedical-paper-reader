# BioReader App — 本地文献精读 + 图库 + 笔记 + 公众号导出

基于 [biomedical-paper-reader](../SKILL.md) skill 方法论打造的本地单用户文献阅读应用。
功能思路融合了作者的另外两个项目：**ReadBox**（几何解析取图、读图模型、证据溯源、长文预算、错误分类）与 **CiteBox**（DOI 导入、Semantic Scholar 相关文献、标签）。

PDF 导入 → 双栏阅读 → 图片自动提取 → 精读/速读双模式笔记 → 图库插图 → Markdown / Word / 公众号导出。

零构建步骤：后端 FastAPI + 前端原生 JS（pdf.js / marked / highlight.js / docx 随应用提供），`./app/run.sh` 即用。

## 快速开始

```bash
./app/run.sh          # 默认 http://127.0.0.1:8765，可用 PORT=9000 ./app/run.sh 改端口
```

Python 依赖见 `backend/requirements.txt`（fastapi、uvicorn、pypdf、httpx、python-multipart、
pdfplumber、pypdfium2、Pillow）。

## 阅读工作台

- 桌面窗口并排展示文献库、论文原文和阅读笔记；原文标题旁可收起文献库，分隔条可拖动或用左右方向键调整。
- 窗口宽度不超过 900px 时，使用顶部「文献库 / 论文原文 / 阅读笔记」切换，避免三栏挤压。
- 所有界面图标使用内置 SVG，无额外图标库或构建依赖。`⌘/Ctrl+K` 聚焦文献搜索。
- 「笔记 / 编辑 / 图库」切换内容；笔记右上角显示保存状态，`⌘/Ctrl+S` 立即保存。
- 论文标题下的期刊与年份可展开完整作者、DOI 等信息；导出操作统一收在「导出」菜单。
- 读图追问与图注编辑使用弹窗；留空追问表示整体观察，取消或 Esc 不发起读图。
- 设置中的模型连接与研究方向常显；生成上限和相关文献 API Key 收在「高级设置」。

## 阅读进度、待办与证据

文献库新增「阅读进度」「阅读决策」「待办」筛选，可与搜索、收藏、标签同时使用。「清除筛选」恢复全部文献。每篇文献的待办按钮可以直接进入对应操作。

- **阅读进度**：未读、已速读、精读中、已完成；在论文标题下手动标记。生成 AI 笔记不会自动把论文标成已读。
- **阅读决策**：待判断、优先精读、留作参考、暂不相关，与进度独立保存。旧文献默认未读、待判断，不根据已有笔记猜测阅读完成情况。
- **自动待办**：待判断阅读价值、待补全文、继续精读、笔记未完成、材料更新待核对、证据待核查。暂不相关的论文不再提醒补全文或继续精读。
- **笔记完整性**：生成中断且已有输出时保留部分笔记及未完成标记，普通编辑不会清除该标记。手动补完后点击「已手动补完笔记」，或成功重新生成。
- **材料变化**：增加或移除补充 PDF、替换正文后，已有笔记会提示核对新材料；可以核对后点击「已核对新材料」，或重新生成。仅编辑笔记、自动配图不会自动解除提醒；生成期间发生的材料变化也会保留提醒。
- **关键证据**：「证据」标签页添加待核查判断、原文摘录或图表观察，选择来源文件、PDF 页码和可选的图表。笔记里选中文字后点「记证据」，会将它带入判断栏；摘录和来源由你补充核实。证据状态分为待核查、已核查、不支持该判断。
- **回到原文**：证据卡片跳转到所选文件的 PDF 页码；笔记中已有图片也显示「查看原文」入口。页码指 PDF 文件内页序号。源文件替换后已核查证据重新待核查；源文件移除后保留证据文本并明确提示来源不可用。
- **保存保护**：证据草稿或保存请求未完成时阻止切换文献和修改材料；可切换到原文核对，再回到证据页保存或取消。保存失败保留输入，不把失败显示为成功。

进度和决策保存在每篇文献的 `meta.json`，证据独立保存在 `evidence.json`。证据为人工整理，不自动从报告推断原文引文，也不会由 AI 自动确认。Markdown／Word／公众号导出会附上已保存的证据与资源记录，保留待核查、驳回及来源失效等状态。

## 数据与代码

左侧「数据与代码」进入全库资源索引；打开论文后的同名标签页可整理该文献的资源。通过「当前论文／全部文献」切换范围，按名称、仓库编号、研究对象、组织、技术、备注或论文标题检索。

- **手动整理**：资源名称、类型（数据集／代码／其他）、仓库、编号或链接，以及与本文的关系（本文产生／复用已有数据／方法实现／关系待确认）。编号和链接至少填写一项；只记录编号也可保存，不会猜测下载地址。
- **细节与来源**：展开补充信息填写研究对象、组织、技术类型、备注，以及可选的正文／补充 PDF 页码与原文依据。只有 DOI 元信息、尚未添加 PDF 的条目也可保存无原文位置的资源。
- **跨论文关联**：相同仓库和编号的记录会显示关联论文，各篇分别保留本文产生或复用等关系。同一篇重复记录相同编号或链接会提示编辑已有记录。GSE／GSM 和 SR 系列编号可在仓库留空时识别为 GEO／SRA；其他仓库请填写清楚。
- **核对与跳转**：新记录默认待核对；可以标记已核对，也可跳转到关联的 PDF 页码或打开资源链接。来源 PDF 移除或变化时保留记录，已核对状态重新待核对。此状态是阅读者的人工标记，不代表应用验证了远端数据能下载。
- **待办与草稿**：尚未核对的资源加入文献待办；保存失败保留输入，未保存草稿会阻止切换论文、修改材料或导出，避免遗漏。全库只查看与跳转，编辑在所属论文中完成。
- **导出**：Markdown ZIP、Word 与公众号内容统一增加「阅读核查与资源记录」附录，包含证据、资源、链接、与本文关系及当前核查状态；不修改编辑器中的原笔记。即使没有正文笔记，也能导出该篇已保存的证据和资源。Word 中资源链接可点击，ZIP 保留原有图片。

每篇文献的资源保存在 `resources.json`。本轮不自动提取编号、不查询远端仓库或下载数据；全库索引只检索本地已记录的资源。外部链接只接受 HTTP(S)，关联到 PDF 的页码按文件页序号计算。

## 配置 API（右上角 设置）

| 字段 | 说明 |
|---|---|
| Base URL / API Key | 任意 OpenAI 兼容接口（BigModel / DeepSeek / OpenAI…），不允许 localhost / 内网地址 |
| 文本模型 | 写笔记、长文分段整理和主题标签识别用 |
| 读图模型（可选） | 填视觉模型（如 `glm-4.6v`）后，生成精读笔记前会先让模型逐张观察主图，观察结果随图注一起进入提示词；图库中「读图 / 全部读图」可单独触发 |
| 送入模型的最大字符数 | 超出时**不再粗暴截断**：自动按页分段整理成带页码的要点笔记（并发压缩、进度可见），再写报告 |
| 单次输出上限 | 0 = 接口默认；精读报告较长，建议 16384+ |
| 最多读图张数 | 按页码顺序取前 N 张主图送视觉模型 |
| Semantic Scholar Key（可选） | 相关文献检索用；匿名额度较慢，可免费申请 |
| 我的研究方向（可选） | 写入提示词，让「过滤结论 / 决策卡」按你的方向判断相关度 |

## 功能

### 文献库
- **正文 + 补充 PDF**：先导入正文，再在该文献的阅读器中点击「添加补充 PDF」（支持多份）。下拉框在各文件间切换，页码分别计算；生成笔记联合读取正文、补充方法和补图，并保留文件来源。添加材料不会自动改写旧笔记，需重新生成以更新分析。重复文件会提示，错误文件不会替换正文。
- **继续阅读**：每篇文献记住最近打开的正文／补充文件，各文件独立保存页码、缩放和适宽设置。切换文件或重新打开 App 后，再打开文献即可恢复；位置保存在本地文献目录，不依赖浏览器端口，也不会改写笔记。
- **长 PDF**：只渲染可见页及相邻页，滚远后释放画布；跳页优先显示目标页，单页加载失败可点击重试。横竖版混排按最宽页适宽；手动放大仍可横向滚动。图库卡片的「查看原文」自动切换到对应文件和页码。
- **导入 PDF**：点击或拖拽（≤80MB）；几何解析器自动产出**双栏正确阅读顺序**的全文（含章节标题识别），
  并按图注锚定**提取全部主图与子图**（图注合并整理、期刊页眉页脚过滤、面板字母切分）。
- **DOI 导入**：贴 DOI / doi.org 链接 → CrossRef 拉取标题、作者、期刊、年份、摘要建条目 →
  中间面板「附加 PDF」补文件（附加不会覆盖 CrossRef 元数据）。
- **元数据补全**：文献标题旁「补全文献信息」按钮用 CrossRef 补作者/年份/期刊（已有字段不覆盖）。
- **收藏 / 搜索 / 标签**：精读／速读笔记成功保存后自动识别主题标签；已有文献可在标题下点击「识别标签」补全，无需重写笔记。也可回车手动添加、点 × 移除，侧栏标签常显并可直接筛选。自动识别使用当前文本模型，增加一次简短请求；未配置 API Key 时可继续手动管理。识别只补充标签，不删除已有标签；失败可重试，不影响已保存笔记。

### 阅读与图片（取图思路来自 skill 的问题驱动核查）
- 左侧 pdf.js 渲染（翻页/缩放/适宽/分隔条）。
- **图库标签页**：全部图片卡片（缩略图/图注/页码/来源），点缩略图放大，
  「图注」「删除图片」「插入笔记」；「重新提取」保留手动图与已有读图观察（ReadBox 合并规则）。
- **手动取图**：PDF 工具栏进入取图模式，在页面上拖框截取任意区域（矢量图、扫描件、跨页图的兜底），
  手动裁图以 3 倍分辨率渲染，保证面板标签与统计标注可读。
- **读图（问题驱动）**：任何一张图（含刚裁的）都可以立刻让读图模型观察，
  并可带具体追问（如「F 面板两组的差别和显著性？」）；配置了读图模型时，裁图完成后自动弹出追问。
  观察结果缓存在卡片上，随图注一起进入笔记生成材料。

### 笔记生成（SSE 流式）
- **完整精读**：skill 报告模板（开篇导读 → 逐图精读 → 课题借鉴 → 复现入口）。
- **速读筛选**：一分钟判断值不值得精读。
- 引用遵循 skill 的自然引用原则：图号／面板／小节定位（如「Fig. 3B–D 展示……」），不逐句标页码；图片清单（图注 + 视觉观察）随提示词注入。
- 手动笔记按顺序自动保存；保存失败时内容保留在编辑器中，可按 ⌘/Ctrl+S 重试，保存完成后再切换文献。
- 生成中显示分阶段进度（读图 x/y、长文整理 x/y），可随时停止并保留已生成部分。
- 停止或连接中断时保留并保存已生成部分，标记“未完成”；生成没有产出时保留原笔记。
- 上游错误分类为可操作建议（上下文超限/输出超限/图片被拒/模型名错/鉴权/限流），不回显原始报文。

### 相关文献（CiteBox 思路）
- 文献标题旁「相关文献」按钮 → Semantic Scholar 该文的**参考文献**与**引用本文**（按被引排序），
  逐条「导入」按钮直接按 DOI 入库；结果缓存 7 天，可强制刷新。

### 导出
- **自动配图**：新生成笔记按有效引用放图，遗漏的主图与补图自动补到对应图标题或「原文图集」；速读只配实际提到的图。旧的纯文字笔记在 Word、Markdown ZIP 和公众号导出时也会自动配图。若想在编辑器中保存配图版，使用导出菜单的「为已有笔记自动配图」（不调用 AI）。
- 自动配图只使用图库中实际存在的图片，不等于视觉核查；没有提取出图片时仍需手动取图。图片文件缺失会提示，避免悄悄导出无图版本。
- **Markdown + 图片**：默认导出 ZIP，包含 `report.md` 与 `assets/*.png`；引用使用相对路径，解压后一起移动即可显示图片。
- **Word 文档**：docx 文档（标题层级、可编辑表格、代码、图片内嵌），按需加载本地 docx 库。
- **复制到公众号**：「导出」菜单中按所选主题排版并复制（4 套主题，菜单内下拉切换），
  mdnice 同款管线（CSS 全内联、伪元素转 span、代码 `<br>`+NBSP 加固、外链转脚注）；
  笔记里 `![Figure X](figure:xxx)` 的图片自动内嵌 base64，粘贴进公众号编辑器不丢图。

## 数据位置

```
app/data/
├── settings.json          # API 配置
└── papers/<id>/           # 每篇一个目录
    ├── paper.pdf / text.txt / meta.json
    ├── supplements/<id>.pdf / <id>.txt  # 独立补充文件及文本，清单在 meta.json
    ├── reading/<document-id>.json      # 各 PDF 的阅读位置，独立原子写入
    ├── evidence.json      # 关键判断、来源页码与人工核查状态
    ├── resources.json     # 数据与代码、本文角色和可选原文依据
    ├── figures.json       # 图片清单（bbox、图注、读图观察）
    └── figures/*.png      # 裁取的图片
```

`app/data/` 已 gitignore。API Key 明文存于本地 settings.json，仅用于向你配置的接口发起请求。

## HTTP API（节选）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/api/papers` | 列表 / 上传 PDF |
| POST | `/api/import/doi` | CrossRef 元数据入库（重复 DOI 409） |
| POST | `/api/papers/{id}/file` | 附加/替换 PDF（保留已有元数据与手动图） |
| POST | `/api/papers/{id}/supplements` | 添加补充 PDF，保留正文和旧笔记 |
| GET | `/api/papers/{id}/file?document_id=<id>` | 获取指定补充 PDF；main 为正文 |
| DELETE | `/api/papers/{id}/supplements/{id}` | 移除补充，保留旧笔记引用的图片 |
| PUT | `/api/papers/{id}/reading-position?document_id=main` | 保存指定 PDF 的 page / scale / fit_width；GET 文献返回 reading_position |
| POST | `/api/papers/{id}/notes/illustrate` | 为传入笔记自动配图，不调用 AI |
| POST | `/api/papers/{id}/export.zip` | 导出 Markdown、图片及证据／资源附录 |
| POST | `/api/papers/{id}/notes/export-preview` | 生成带附录的导出内容，不改写笔记 |
| GET/POST | `/api/papers/{id}/resources` | 读取／新增该文献的数据与代码 |
| PATCH/DELETE | `/api/papers/{id}/resources/{rid}` | 编辑／删除资源记录 |
| GET | `/api/resources?q=` | 本地全库资源检索与关联论文 |
| POST | `/api/papers/{id}/enrich` | CrossRef 补全元数据 |
| GET | `/api/papers/{id}/related` | S2 参考文献/被引（缓存 7 天） |
| GET/POST | `/api/papers/{id}/figures` `/extract` `/crop` | 图库 / 重提取 / 手动裁图 |
| PATCH/DELETE | `/api/papers/{id}/figures/{fid}` | 改图注、观察 / 删除（子图级联） |
| POST | `/api/papers/{id}/figures/{fid}/read` | 单图读图（可带追问，观察缓存） |
| POST | `/api/papers/{id}/figures/read` | 批量读图（SSE，观察缓存） |
| POST | `/api/papers/{id}/read?mode=deep\|quick` | SSE 流式生成笔记 |

出站请求仅限三类：你配置的 LLM 接口（SSRF 校验 + 重定向逐跳复检）、`api.crossref.org`、
`api.semanticscholar.org`（主机白名单）。

## 已知边界

- 图注锚定取图依赖 PDF 内嵌文本/对象几何；纯扫描件走 pypdf 文本兜底 + 手动取图。
- Semantic Scholar 匿名额度有限（约 1 请求/秒，共享池），频繁使用建议填免费 API Key。
- OCR 未内置（ReadBox 有 Tesseract 管线，本应用为保持轻量暂未移植）。
- 公众号粘贴对代码块已加固；数学公式仍建议截图插入。
