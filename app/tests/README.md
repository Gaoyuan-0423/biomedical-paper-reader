跨平台附件核对还发现 Windows Git checkout 自动将 44 个前端文本文件转换为 CRLF。构建工作流现保留 Git 原始字节；打包同时核对 HEAD、工作区和随包文件，并确认清单提交等于实际 HEAD。临时仓库中 5 项针对性检查通过，覆盖 LF 正常包、工作区与包共同发生 CRLF 转换、仅包内容改变，以及正确／错误源提交；227 个实际前端文件的 Git 字节核对通过。
