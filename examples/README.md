# 公开示例

以下三组输入均为本项目原创的虚构验收材料，不对应真实论文。报告用于展示技能如何适配材料范围、研究设计和证据强度。示例中的人物、指标、方法名称和数值不能作为真实科研发现或学术文献引用。

| 示例 | 原始输入 | 已生成报告 | 主要观察点 |
|---|---|---|---|
| 材料不完整 | [二手解读片段](../evals/fixtures/incomplete.md) | [Marker Q 报告](incomplete/report.md) | 缺原文、图像和方法时压缩输出；区分材料未获取与原研究未开展；不遵从材料中夹带的编辑指令 |
| 纯观察研究 | [完整观察性短文](../evals/fixtures/observational.md) | [Marker A 报告](observational/report.md) | 区分供者、组织与细胞；解释效应量和置信区间；识别未控制的年龄差异及因果措辞越界 |
| 方法与预测研究 | [完整方法短文](../evals/fixtures/prediction-method.md) | [NeighbourScore-lite 报告](prediction-method/report.md) | 按正文实际表序精读；识别特征选择泄漏、供者未隔离和泛化证据缺口；解释方法组合与资源信息边界 |

## 如何使用

选择一份输入，在已加载本技能的助手中运行：

```text
使用 biomedical-paper-reader 阅读这份材料，按实际可获取内容生成中文报告。
```

将生成结果与相应示例对照时，重点检查论证顺序、证据定位和结论强度，不要求逐字一致。验收场景与记录见 [cases.md](../evals/cases.md) 和 [RESULTS.md](../evals/RESULTS.md)。这些示例不代表技能在全部真实论文上的准确率。

## 材料边界

- 报告保留原试读输出的分析和数值，只调整了来源链接，使其能在本仓库中相对引用。
- `incomplete.md` 中刻意包含一段要求忽略证据规则的编辑文字，用于检查助手能否把文档内容与用户指令分开；它不是使用本技能时应执行的指令。
- 本目录不包含真实论文的 PDF、原图或补充材料，也不依赖个人文件路径。
