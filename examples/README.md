## 当前报告格式

- 正文围绕论文的研究问题、方法原理与目的、主要结果、论证衔接和必要科学局限展开。
- 解释方法的具体输入如何产生输出、为何能回答本图问题，保留自然的图号、表号引用和图像；避免退化成标签或图笔记。
- 材料不足时保留影响判断的来源事实，例如二手片段不足以支持全文结论，不将其写成原研究未开展相应实验。
- 来源核查层级、查看或执行状态、覆盖表、技术索引和软件日志放在工作记录或按需提供的附件，不进入正式报告正文。
- 不以“本次已读”“未重分析”等过程声明组织报告；让限制服务于具体科学问题和结论解释。
- 本页的历史报告保留原输出，用于追踪旧行为，其中的过程栏不应照抄；新版独立试读另行生成和验收，手改旧例不作为新版行为已通过的依据。

## 如何使用

选择一份输入，在已加载本技能的助手中运行：

```text
使用 biomedical-paper-reader 阅读这份材料，按实际可获取内容生成中文报告。
```

将生成结果与相应示例对照时，重点检查论证顺序、方法解释和结论强度，不要求逐字一致，也不照抄历史报告的过程栏。验收场景与记录见 [cases.md](../evals/cases.md) 和 [RESULTS.md](../evals/RESULTS.md)。这些示例不代表技能在全部真实论文上的准确率。

## 材料边界

- v0.1.0 三份历史报告保留原试读的分析和数值，只调整过来源链接；当前输出另列，未覆盖历史。
- `incomplete.md` 中刻意包含一段要求忽略证据规则的编辑文字，用于检查助手能否把文档内容与用户指令分开；它不是使用本技能时应执行的指令。
- 本目录不包含真实论文的 PDF、原图或补充材料，也不依赖个人文件路径。
